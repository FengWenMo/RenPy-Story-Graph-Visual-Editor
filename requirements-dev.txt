# 开发依赖（跑测试用）
# =========================
#
# 运行时依赖只有 openpyxl（见 README）；Pillow 是可选的缩略图依赖。
# 这里只放"跑测试"需要的东西。
#
#   python -m pip install -r requirements-dev.txt
#
# **本机注意（已实测）**：pip 在写**系统临时目录**时会被沙箱拒绝，
# 表现为"pip 卡住不动"，实际是
#   PermissionError: ... pip-unpack-...whl
# 不是网络问题。把 TMPDIR/TEMP/TMP 指到仓库内即可：
#
#   $env:TMPDIR = (Resolve-Path '.pip-tmp').Path
#   $env:TEMP = $env:TMPDIR; $env:TMP = $env:TMPDIR
#   python -m pip install pytest
#   python -m pytest -q
#
pytest>=8

# ⚠ **依赖必须在这里也列一遍**（2026-10-21，CI 全红的原因）：
# GitHub Actions 只跑 `pip install -r requirements-dev.txt`，而这里从前只有
# pytest —— 于是 `import openpyxl` 在收集阶段就炸，三个 Python 版本全挂在
# 「跑全量测试」的第 10 秒（本地能过，因为开发机装了 requirements.txt）。
#
# 为什么**不写** `-r requirements.txt`：那会把 PySide6 一起拖进 CI（Linux 上
# 还要补 libegl / libxkbcommon 等系统库，多一个失败点）。UI 测试都有
# `pytest.importorskip('PySide6')`，没装就整批跳过 —— CI 跑"无界面那 5000 条"
# 足够挡住回归，界面相关的仍在本机全量跑。
openpyxl>=3.1
Pillow>=10
