# 3 分钟上手（Windows 免安装包）

> 这一份会随发布包一起发出去（`快速上手.md`）。写给人看，不是给开发者看。
> 不需要 Python、不需要装 Ren'Py 就能打开界面；**验证导出**才需要 Ren'Py SDK。
>
> 想看得更细（每个按钮、常见问题、命令行）就看同目录的 **`新手快速操作手册.md`**；
> 工具栏右端的 **❓ 使用说明** 里有完整五页。

## 1. 解压，然后双击

1. 把 zip **整份解压**到一个固定目录（`StoryGraph.exe` 依赖同目录的 `_internal\`，
   别只把 exe 拖出来）。
2. 双击 `StoryGraph.exe`。第一次打开是空的 —— 它不自己找项目。

> 有的机器会弹"Windows 已保护你的电脑"：点「更多信息」→「仍要运行」。
> 这个包没有代码签名（个人项目，签名要证书），所以会有这一下。

## 2. 打开一个项目

**包里有 `demo\` 的话**（示例工程，只有标准版带），先拿它练手：
点顶部「📁 打开项目」，选解压目录里的 **`demo`** 文件夹（含 `game\` 和 `asset_tables\`）。
**包里没有 `demo\` 的话**（程序版），直接选你自己的项目根 ——
就是那个里面有 `game\` 文件夹的目录。

1. 左侧「▥ 章节导航」里出现 `ch01.rpy → ch01`；**双击 `ch01`** 进卡片页。
2. 中间左是这一章的**每一拍**（行号 + 类型牌：对白 / 旁白 / 分支 / 调用…）；
   右边是这一拍的**卡片**，最上面「▸ 定位」是收起的，点开才看文件 / 第几拍 / 源在第几行。
3. 改一句台词 → 点「💾 保存这一拍」（只动内存）→ 点「⤓ 导出 .rpy」写回磁盘。
   导出前会给你结论：增量补丁改了几行 / 原生内容有没有被保住。

想看图：点顶部模式条切到 **🗺 剧情结构**，工具栏「➕ 导入章节 .rpy」选这一章的
`.rpy`（demo 就是 `demo\game\script\ch01.rpy`）—— 图上出现一个块，按住
**Shift + 左键** 从一个块拖到另一个块就是接线（demo 只有一章，接给下一章时用）。

## 3. 从自己的 Excel 开始

1. 把 `剧本空表格.xlsx` 拷进你的项目（或直接编辑你已有的剧本表）。
2. 按表里的「列说明」填：`章节 / 类型 / 说话人 / 台词 / 条件 / 舞台 …`。
3. 打开工具 →「打开项目」→ 卡片页「⤒ 从剧本表写回」→ 选那张 `.xlsx`。
4. 想反过来（已有 `.rpy` → 表）：命令行
   `StoryGraph-CLI.exe table rpy2xlsx <你的项目>\game\script\ch01.rpy` 生成同名 `.xlsx`。

## `storygraph.rules.json` 是干什么的

exe 旁边那份 `storygraph.rules.json` 是**规则清单**：它告诉工具"这个项目里
有哪些语句、每条语句的每一栏该填什么、候选值有哪些"。

- 没有它，工具只认 Ren'Py 内置语句（`show` / `scene` / `play` …）；你自己
  在引擎里加的语句（`weather6 rain` 这类）在界面上就只是一串裸文本 ——
  能原样导出，但没有分栏、没有候选、没有校验。
- 随包带的是**一份真实项目在用的清单**（含角色名、语句分栏），可以直接照
  着改成你的。
- exe 旁边还有一份 `storygraph.mapping.json`：**立绘代号表**（服装字母
  `A/B/C` + 表情编号，`lan B7` ⇄ `show lan base_hand_up angry`）。它和 rules
  同源、一起发，但**不会**自动套进项目 —— 在「🗂 资源映射 → 载入映射…」里挑它。
- **怎么用**：把它复制到你的项目根（和 `game\` 同级，文件名保持
  `storygraph.rules.json`）；项目里已经有这个文件就**别覆盖**。
  也可以在界面里一条条"教会"工具，它会把结果写进这个文件
  （命令行是 `StoryGraph-CLI.exe learn`）。
- 工具**不会**自己往你的项目里写任何东西 —— 标准版没有任何"打开就改项目"
  的行为，这一步永远是你手动做的。

## `storygraph.mapping.json` / `.xlsx` 是干什么的（可选）

工具默认能自己推断"哪张图是哪个角色的哪个表情"（看资源表「标签」列、看文件夹名）；
推断不出来时它**不会瞎猜**，会标成「未识别」。**资源映射**就是给项目补一份
"人话对照表"：

- 菜单栏 **`🗂 资源映射 → 导出映射初稿…`** 会按你项目的真实目录生成一份草稿；
- 草稿可以存 **JSON**（可 diff、可提交）或 **Excel**（一千多行的表在 Excel 里改最省事；
  同一目录 Excel 优先，状态栏会写 `（Excel）`，工具只读不回写）；
- 「资源对照表」里核对（可只看未识别），改完 **`保存到项目根`**（先给你看 diff）；
- 里面还能放**代号表**两段（`outfit_codes` / `expression_codes`）：`A` = 哪套衣服、
  `7` = 哪号表情，给剧本注释 `# 表情B7` 和美术需求表用；证据不够的字母**留空**
  等人填，工具不按顺序猜。
- 文件跟着项目走、可提交、可 diff，也能直接发给别的项目开发者照格式填自己的；
- 详细格式见项目里 `docs/资源映射_给项目开发者.md`，可直接发人的样例在
  `examples/mapping/` 下。

## 三条要知道的规矩

- **它不改你没动过的字节**：只替换真正改过的那几行；对不上就整份放弃并报错，
  绝不产出"半对"的脚本。**这句现在是断言**：补丁说"0 行改动"而产物与原文
  不一样时，工具会拒绝写盘（不再有"悄悄改了一处"这种状态）。
- **它不改引擎**：所有产物都是标准 Ren'Py 脚本，随时可以卸载这个工具继续手写。
- **带 `# 由剧本表自动生成` 首行的文件是工具产物**：改它的结构请回表里改，
  直接在文件里改结构会被下次导出覆盖（改台词不受影响）。
  *第一次*导出某份章节时，工具会在首行加 **2 行**（标记 + 一个空行），
  全文行号因此下移 2 —— 回执里会明确说出来，第二次起不再变。
- **「备注」列自动补 `#`，「舞台（高级）」列一个字都不动**：后者是**代码**，
  写什么就出什么。看着不像语句的内容、或者 `show` 的名字项目里根本找不到，
  导出前会问你一句（可原样导出 / 取消 / 去改）—— 不会静默写出去。

## 覆盖与备份（重要）

- **每一次覆盖之前都会先备份**，而且**不覆盖上一代备份**：
  第一份是 `名字.bak`（它通常才是你手写的原件），之后是
  `名字.bak-20261101-120000-123456` 这种带时间戳和序号的，最多留 5 代
  （不会无限长大）。
- **备份失败就不写**：磁盘满 / 权限不足 / 杀毒软件占着文件时，工具**中止**整次写入，
  原文件一个字节都不动（不会出现"以为有 .bak、其实没有"）。
- **Excel 只写进 `.xlsx`**：把 `.rpy` 或别的路径当表格传进来会被**直接拒绝** ——
  这是"一个参数毁掉一章剧本"那条路的最后一道闸。
- 所有写盘都是**整份替换**（同目录临时文件 → 刷盘 → 一步换名）：
  断电或崩溃时，磁盘上要么是旧的完整文件、要么是新的完整文件，不会有半截。

## 命令行（可选）

`StoryGraph-CLI.exe` 是同目录下的无界面版，适合批量/CI：

```bat
StoryGraph-CLI.exe validate <项目目录>
StoryGraph-CLI.exe compile <剧本表.xlsx> --source <这一章原来的.rpy>
StoryGraph-CLI.exe table rpy2xlsx <项目>\game\ch01.rpy
StoryGraph-CLI.exe excel-check <某张表.xlsx 或 某个目录>
```

**退出码是给 CI 看的**（`0` 通过 / `1` 有错误或被门禁拦下 / `2` 用法或环境问题）：

- 路径不存在、传了个目录、后缀不对、项目目录里一个 `.rpy` 都没有 → **退出码 2**，
  并点名到具体路径（从前这些情况全都"成功"，还给你一张只有表头的空表）；
- 文件读到了但一条语句都没有、台词引号没闭合、跨文件 label 重名 → **退出码 1**。

排错加 `--debug`（等价于环境变量 `STORYGRAPH_DEBUG=1`）：被兜住的每一处错误都会
打到 stderr，异常也不再多绕一层；不加时，命令**成功但有东西被吞掉**会在最后
补一行摘要。

## 读 Excel 之前会检查什么

Excel 文件本质是个压缩包，里面装什么由做它的人决定。所以**每次打开表之前**
都会先看一眼（不解压），分两档：

- **直接拒绝**（并说明原因）：解压炸弹（几 MB 解开几百 MB）、表头声明的范围
  大到离谱（`A1:XFD1048576` 那种）、加密文件、老式 `.xls`、改了后缀的假表格；
- **只提醒**：带宏（`.xlsm`）、外部链接、嵌入对象、数据库查询连接 —— 这些不会
  被执行，但"读回来的可能不是这份文件里的值"，你有权知道。

想自己先查一遍：`StoryGraph-CLI.exe excel-check <表或目录>`
（打不开 → 退出码 1；只提醒 → 退出码 0，加 `--strict` 才算失败）。
体检（`validate`）也会把这类表报成 **E307**（打不开）或 **W123**（有提醒）。

更多（协作锁、状态流、保真体检、多引擎导出）见项目里的 `docs\`；
`LICENSE` 是 **GPLv3**，第三方组件说明在最后一段。

## 系统要求（图形界面）

- Windows 10 / 11 x64。**图形界面依赖系统的 `icuuc.dll`**（Win10 1607 起自带），
  所以老 Windows、Windows Server Core、精简镜像和 **Wine** 上**界面起不来**
  —— 这时会弹一个明确的对话框说明缺什么，而不是"双击了没反应"。
- 命令行版**不受影响**：体检 / 导表 / 导出都能用。
- 不知道自己机器行不行：跑一下 `StoryGraph-CLI.exe selfcheck`，
  里面有一项「系统 DLL（图形界面依赖）」。
