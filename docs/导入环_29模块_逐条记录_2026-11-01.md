## 一、量的口径

- 工具：`tools/debt_report.py`（只数个数）+ `tools/cycle_edges.py`（拆到每条边）。
- "环" = **强连通分量（SCC，成员 > 1）**。这里的图**包含函数体内的
  `import`** —— 项目大量用延迟 import 破环，若只看模块级导入，环数是 0
  （`import_cycles_top = 0`），但那只是"债换了形态"，不是没了。
- 模块名按**包的前三段**归一（`storygraph.story.beat_model`），
  `from storygraph.story.x import y` 记作一条指向 `x` 的边。

## 三、三条真正的"方向违规"

其余边大多是同一层内部的（`beat_render → beat_model` 这类"上层用下层"，
方向本来就对）。会让环闭合的是这几条**反向**边：

| 反向边 | 为什么是违规 | 次数 |
|---|---|---|
| `story.statement_registry → pipeline.build` | `pipeline` 是**上层**（编译/校验/导出），`story` 是下层；下层调上层的 `load_asset_registry` | 1 |
| `story.script_table → pipeline.compile` | 同上（`export_table_to_rpy`） | 1 |
| `story.generation_guard → pipeline.engine_lint` | 同上（`lint_text`） | 1 |
| `assets.asset_registry → story.script_table` | `assets` 是被 `story` 依赖的底座，反过来调 `registry_from_parse_result` | 1 |
| `assets.asset_registry(_scan) → story.excel_export` | 同上（`resolve_thumb_source`：**缩略图路径解析本该住在 assets 里**） | 2 + 4 |
| `story.dsl → assets.asset_registry` | `dsl` 是脚本文本层，却要 `AssetIndex` / `resolve_references` | 4 |
| `story.beat_model → story.beat_render` | `beat_model` 是 `Beat` 本体，反过来要 `_bracket_delta` / `_quote_state`（两个**纯文本扫描**函数） | 4 |

另外两对是**互引**（A 要 B 的一个函数、B 要 A 的一个函数）：

- `story.project_conventions ↔ story.host_hooks`
  （`unknown_statements` 要 `load_host_hooks`；`trust_decision` 要 `load_manifest`）
- `pipeline.engine_lint ↔ pipeline.engine_collect`
  （`find_sdk` / `declared_heads_near`）

## 四、要解环，处理这 12 条就够（近似最小反馈边集）

## 五、为什么这一轮没动手

不是排期问题，是**方法**问题：**删掉单条边不会缩小环**。
SCC 的判据是"任意两点互相可达"—— 只要还剩一条别的路径，29 个模块照样
全在里面。所以正确顺序是：

1. 先按上表把**方向违规的 7 条**处理掉（多数是"把函数搬到它该在的层"，
   例如 `resolve_thumb_source` → `assets/`、`_bracket_delta` → `story/beat_text.py`）。
   每处理完一条，重新跑 `debt_report.py` 看 SCC 有没有缩小；
2. 再处理两对互引（把共享的那个函数**下沉**到更低的模块，
   而不是在两边各留一份）；
3. 最后剩下的 `pipeline` 内部互引（`engine_lint ↔ engine_collect`、
   `engine_exporters ↔ ir_validate`、`unity_package → engine_exporters`）
   是同一层内的组织问题，可以按"职责"合并或下沉到 `pipeline/_engine.py`。

⚠ **一个坑必须先说**：拆的过程里 **`import_cycles_all`（环的个数）可能先涨**
—— 一个大环拆成两个小环，个数是 2 不是 0，而"模块总数"已经在降。
`tests/tech_debt_budget.py` 同时钉了 `import_cycles_all` 与
`modules_in_cycles_all`，后者才是"债有多大"；重生成预算时**两个都要看**，
别为了个数好看把两个小环又合并回去。
