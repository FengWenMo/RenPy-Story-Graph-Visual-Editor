>
> > ① 如果我在一个过程中 call 了，后面直接又想在图上加回这条边怎么办？
> >    我知道第……行有一个 call，那是我在卡牌编辑器内写的；但切换到块状编辑器，
> >    我只知道有一个 call、条件是什么或者 menu 是什么，**我并不知道 call 在哪个位置**。

> > ② 草图锚点到底是什么意思？我需要更详细的分析。
>
> **一句话回答**：工具**判断不了**"合适"——那是编剧的判断。工具能做的是四件事：
> **看得见位置、选得定位置、找得回位置、绝不替你猜位置**。下面用例子把这四件事和"锚点"讲透。

---

## 一、先说清楚：问题不在"删"，在"位置"这一维

调用不是一条纯粹的"从 A 到 B"的关系。它其实是：

> **在 A 章的第 N 拍，发生了 call B。**

这句话有三个成分：

| 成分 | 图上看得见吗 | 今天的现状 |
|---|---|---|
| 从哪（A 章） | ✅ 边的起点 | 有 |
| 到哪（B 章） | ✅ 边的终点 | 有 |
| **在哪一步发生（第 N 拍）** | ❌ **看不见** | 边上有 `line_id`（如 `ch01.0007`），但**没画出来** |

你问"我并不知道 call 在哪个位置"——对，因为图把第三个成分**藏起来了**。
它存在于数据里（`Edge.line_id`），但界面上没显示。所以你在图上看到一条边，
只知道"main 调了 side"，不知道"是在第 3 拍调的（'我们走吧'之后、'到了'之前）"。

**这就是一切混乱的根源**：图是空间的（谁连谁），调用是时序的（在哪一步发生）。
你在图上删一条边、加一条边，操作的是空间关系；但写回脚本时，必须落到时序里的某一步。

## 二、用一个具体例子走一遍

假设 main 章现在是这样（卡片里的样子）：

```
第 1 拍   e "我们出发吧"
第 2 拍   e "等等，带上武器"
第 3 拍   call side            ← 就是这个 call
第 4 拍   e "到了"
```

图上画着：`[main] ──call──▶ [side]`，边上可能还写着条件或菜单文字。

### 场景 A：我只是想知道"这个 call 在哪"

**今天**：只能点进卡片，一拍一拍翻到第 3 拍。
**应该**：把边翻过来，看它的"肚子"——

```
┌─ 这条边 ────────────────────────────┐
│  main ──call──▶ side                 │
│  位置：第 3 拍 / 共 4 拍              │
│  前一拍：e "等等，带上武器"           │
│  这一拍：call side                   │
│  后一拍：e "到了"                     │
│  [跳到这一拍]                        │
└──────────────────────────────────────┘
```

边上有 `line_id`（`ch01.0003`），拍列表里有全部台词——**这两样都有了，
缺的只是把它们显示出来**。这解决"我只知道有一个 call，但不知道它在哪"。

### 场景 B：我想删掉这个 call

这里必须先分清两种"删"：

| 你做的 | 意思 | 今天的实际行为 |
|---|---|---|
| **删图上的边** | 只是把线从图上拿掉 | ✅ 只改内存图，**脚本里的 call 原样还在**（`RemoveEdgeCommand` 只动图模型） |
| **删这一拍** | 把 call 从剧本里删掉 | ✅ 卡片里删拍 → 走受控补丁，图边随后消失（已有） |

⚠ **发现问题 1**：如果只删边、不删拍，下次刷新/重载时，`flow_edges` 会从脚本里
重新派生出这条边——**线又弹回来了**。用户会以为"我删了怎么还在"。

⚠ **发现问题 2**：反过来，如果你真把拍删了，位置信息（"它在第 3 拍"）就没了。
再加回来时，工具不知道该放哪。

### 场景 C：删了之后，我想在图上加回来（你问的核心）

你的期待："它能放在合适的地方"。

**诚实回答：工具判断不了什么是"合适"。** "在决定出发之后、到达之前 call side"——
这是叙事逻辑，只有你知道。工具要是"看着像就放"，那就是**静默改剧情**（铁律 3/4 明令禁止的那类）。

但工具**能**做的是把"合适"变成"你一眼就能选对"：

```
┌─ 加一条 main → side 的 call ──────────────────────────┐
│  插在哪一拍后面？                                       │
│                                                        │
│  ○ 章首（第 1 拍之前）                                  │
│  ○ 第 1 拍之后  e "我们出发吧"                          │
│  ○ 第 2 拍之后  e "等等，带上武器"                       │
│  ◉ 第 3 拍之后  call side   ← 如果最近删过，光标停这    │
│  ○ 第 4 拍之后  e "到了"                                │
│  ○ 章末                                                │
│                                                        │
│  💡 上次这个 call 在「第 2 拍之后」被删掉                │
│     [回到上次的位置]  [用上面选的]  [取消]              │
└────────────────────────────────────────────────────────┘
```

**"合适"是选出来的，不是猜出来的。** 但选择可以被三个信号辅助（见 §四）。

## 三、"草图锚点"到底是什么——这次用例子讲

上一轮我写的"锚点"太抽象了。它的意思拆开是：

### 3.1 草图 = 还没落到剧本上的意图

你在图上画一条 `main → side2` 的线，但 main 章里**还没有** `call side2`。
这条线表达的是一个**意图**："我想让 main 调用 side2"。

它之所以叫"草图"，是因为脚本里还没有对应物——就像在剧本打印稿上
用铅笔画了个箭头，还没誊进正文。

### 3.2 锚点 = "誊进正文时，插在哪一行"

要把草图变成真的 `call side2`，必须回答一个问题：

> **在 main 章的哪一拍后面，插上这张 call 拍？**

这个"哪一拍后面"，就是**锚点**。它不是位置坐标（x/y），而是**时间轴上的插入点**——
类似在 Word 里按下回车之前，光标停在哪。

例子：main 章有 4 拍，你要插 call side2——

| 锚点选在哪 | 插完之后 |
|---|---|
| 第 2 拍之后 | `出发` → `带上武器` → **`call side2`** → `（原来第3拍的call side）` → `到了` |
| 章末 | `出发` → `带上武器` → `call side` → `到了` → **`call side2`** |

**同样是加一条 call，放的位置不同，剧情就不同。** 这就是为什么不能猜。

### 3.3 锚点确认 = 弹窗问你"插在哪一拍后面"

上一轮方案里说的"锚点确认"，就是指**加边时弹出上面那个选拍的对话框**。
就这么一件事，名字起复杂了。

## 四、"合适的地方"怎么辅助判断——三个信号，都不是决策

工具不能替你决定，但可以把决策变得不费脑子：

| 信号 | 什么时候出现 | 为什么可信 |
|---|---|---|
| **① 上次被删的位置** | 这条边（同 from + 同 to）最近被删过 | 你自己放过的那个位置，就是你自己认为"合适"的位置。删了再加是**还原**，不是**重设计** |
| **② 卡片里当前选中的拍** | 你刚在卡片页看过/选中某拍，再切到图上加边 | 你的注意力停在那一拍附近，大概率想接在那里 |
| **③ 章末** | 以上都没有时的**默认高亮**（不是默认写入） | "调个子过程然后回来"是常见写法，所以章末出现频率高——但**仍要你点确认** |

⚠ 三个都只是**预选**，写入前一定要人按一下。工具永远不"替你按"。

## 五、回答你的原话："不管我在哪儿删拍还是删边，如何用模块编辑器处理它？"

统一成一个模型，就清楚了：

> **对 `origin='source'` 的边来说，"边"和"拍"是同一个东西的两张脸。**
> 拍是本体（剧本里真的有一行），边是它在图上的投影。

所以：

| 你在哪删 | 发生什么 | 加回来时 |
|---|---|---|
| **卡片里删拍** | 拍没了 → 受控补丁删那一行 → 边随之消失 | 在图上加边 = 弹锚点确认 = 插回一张拍 |
| **图上删边（source）** | **今天：只删投影，本体还在** → 下次刷新线会弹回来 | 不用加——它还在剧本里；或者升级成"删边 = 连拍一起删"（见判断题） |
| **图上删边（manual 草图）** | 草图没了，剧本本来就没它 | 加边 = 弹锚点确认 = 首次落地 |

**图上"加边"永远等于"在剧本里插一张拍"**——只要这一点不变，
不管从哪删、从哪加，最后都落到同一个动作：**选锚点 → 插拍 → 受控补丁写盘**。

## 六、三个设计决定（比上一轮更具体）

### 决定 1：图上必须显示位置（这是你的第一问的答案）

边上加一个**位置徽标**，不点开就能看见：

```
[main] ──call ③──▶ [side]
```

`③` = 第 3 拍。悬停出前后两拍的台词摘要，点击跳进卡片那一拍。

**为什么这是第一优先**：你说"我并不知道 call 在哪个位置"——这不是删除/新增的问题，
是**读**的问题。读都读不懂，删和加必然心虚。先把位置画出来，后面所有操作都踏实。

### 决定 2：加边必须选锚点，但带三个预选信号

就是 §三/§四的对话框。**尤其"回到上次的位置"直接给一键按钮**——
你的场景（删了想加回来）本质是**还原**，不该逼你重新翻拍列表。

### 决定 3：删边（source）默认只删线，删拍是显式动作

理由：**删比藏危险得多**。你在图上按 Delete，可能只是想把这张图收干净，
不一定想改剧本。所以：

- 按 Delete / 右键"删除这条连线" → 只删线，状态栏写清楚：**"只从图上拿掉了；
  脚本第 3 拍的 call side 还在。要一起删，请点「连同脚本里的调用一起删」。"**
- 想真删 → 二次确认框里写出：**"将删掉第 3 拍的 call side（前一拍：'等等，带上武器'），
  产物会少 1 行。"**——和卡片删拍的确认框同一格式（已有 `_delete_preview`）。

**同时修掉"删了又弹回来"**：只删线时，把这条边记进"用户隐藏列表"（按 line_id），
刷新时跳过它、不再派生回来；撤销或"重新显示"时移出列表。
这样"删线"就是真的删线，不会被工具的好意刷新搞回去。

## 七、回到你的两个问题，一问一答

### Q1：删掉之后想加回来，怎么放回"合适的地方"？

**A**：工具猜不出"合适"。它做的是——
①边上一直显示位置（你知道它原来在哪）；
②删掉后记住位置，加回来时**一键"回到上次的位置"**；
③要另选就列出全部拍的台词摘要让你点。
"合适"最终是你按的那一下，但按之前你**看得到上下文**，不用凭记忆。

### Q2：草图锚点是什么？

**A**：图上画的新线 = 草图（剧本里还没有这行）。**锚点 = 这行最终插在哪一拍后面**。
"锚点确认"就是弹窗问你"插在哪一拍后面"，仅此而已。
之所以必须问：同样加一个 call，放在第 2 拍后和放在章末，是两个不同的故事。

## 八、实施顺序（比上一轮更细）

| 步 | 做什么 | 判据 | 依赖 |
|---|---|---|---|
| **S1** | 边上显示位置徽标 + 悬停上下文 + 点击跳转 | 打开真机项目，任意 source 边能看到"第 N 拍/共 M 拍"与前后台词 | 无 |
| **S2** | 加边弹锚点确认（三个预选信号 + 拍列表） | 不确认零写；确认后插入位置 = 所选位置 | 无 |
| **S3** | 删边（source）只删线 + "用户隐藏列表"防弹回 + 显式"连拍一起删" | 刷新后线不弹回；连删确认框有位置与行数 | S1 |
| **S4** | 删后加回的"回到上次的位置" | 删拍/删边后加同向边，默认停在上次锚点 | S2 + S3 |

S1 只读不写，最便宜，且立刻解决你的第一问（"不知道在哪"）。
S2 是上一轮的 W3（草图落地），加上锚点对话框。
S3 修掉一个今天就存在的怪现象（删了又弹回来）。

## 九、明确不做（依旧）

- 工具自动判断"合适的位置"并直接写入——**永不**。可以预选，不能替按。
- 图上显示拍级细节（台词全文）——徽标 + 悬停摘要够了，点进去看全文（不然图又变成"群岛"）。
- 手画一条线就"自动生成一整章内容"——只插一张 call/jump 拍，内容归卡片写。
