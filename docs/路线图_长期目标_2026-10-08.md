## 三、里程碑

### M1 · 生成器收口（D2）— 🔵 进行中
**目标**：`.rpy` 的"谁生成哪种产物"显式化，且**所有落盘一律过门禁**。

- [x] **控制流导出过 `write_generation`**：带生成标记（`ensure_generator_marker`）、命中 block 就拒写目标路径、写 `<stem>.blocked.rpy` 供对照、结论回给调用方（`export_control_flow` 现在如实报失败）。
- [x] 新增守卫：`test_control_flow_export_goes_through_the_generation_gate` / `..._is_allowed_to_overwrite_its_own_output`。
- [x] 顺带修掉一处**真 bug**：门禁抓到产物里的字面控制字符 `\x01` —— 起因是 `test_exporter` 用了**过期标记**（真标记是 `\ue000`）。判据已校准。
- [ ] **ownership 显式化**：两个模块的 docstring 写明"我产哪种文件、什么时候用我"，并在 `docs/` 留一页对照表。

**验收**：`tools/hell_multi_engine.py` 0 失败；控制流产物过门禁；上面那条"唯一写盘入口"守卫存在且做**突变验证**（加一处裸写 → 变红）。
