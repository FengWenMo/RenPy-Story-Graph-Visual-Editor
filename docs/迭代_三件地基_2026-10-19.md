## 一、资产维度结构化（`storygraph/assets/asset_dimensions.py`）

## 三、协作三件小事（`schema 3`）

| 项 | 落地 |
|---|---|
| WAL + busy_timeout | 连接统一 `journal_mode=WAL`、`busy_timeout=30000`、`synchronous=NORMAL`、`foreign_keys=ON`；WAL 失败不炸连接 |
| 写事务 | push / lock / 状态机 / 资产用 `connect(write=True)`，进入即 `BEGIN IMMEDIATE`（CAS 不再被并发读旧 revision） |
| 锁租约 | `beats.locked_until`，默认 15 分钟；`lock(ttl=)` / `renew_lock` / `locks()` 返回 `expired`/`expires_in`；过期可接手并留审计 |
| 成员权限 | `users.role`：`viewer`/`editor`/`owner`；`viewer` 只读；老库无 owner 允许第一次认领 |
| CLI | `collab members` / `collab role` / `collab renew`、`collab init --owner`、`--ttl` |

## 五之二、跨 Unity 第一片（目标里追加的第 4 项）

> 目标在会话中被追加了"开始加入跨 Unity 引擎的功能，一样全程至少 3 轮
> 自检迭代"。这里只交付**第一片**：把"播放器必需、而 IR 缺"的两个缺口补上，
> **不写 Unity 播放器**。

### 补了什么

| 层 | 字段 | 为什么 |
|---|---|---|
| 中立 IR | `lines[].structure = {path, kind, known}` | 别的引擎拿到 `menu:1>B` 能知道它是选项体里的拍；`known=false` = 老表不知道，别当顶层 |
| 中立 IR | `lines[].timeline = [{op,target,at,clause,transition,action,params,order}]` | `scene/show/hide/with/music/sound/voice/at/transform` 的**作者顺序**；`order` 从 0 递增 |
| Unity 适配 | `structurePath` / `structureKind` / `structureKnown` + `timeline[]` | 保持"标量 + 数组"的 JsonUtility 约束，不塞嵌套字典 |
| Godot 适配 | `structure` / `timeline` | GDScript 能吃嵌套，保留原形状 |
| 生成说明 | `UNITY_IMPORT.md` 的 C# 结构 + 时间轴说明 | 程序不用猜字段 |
| 参考模型 | `docs/unity/StoryIr.cs` + `docs/unity/README.md` | 可直接粘进 Unity 的 `[Serializable]` 类；明确"不是播放器" |

IR schema 从 `1.0` 升到 `1.1`（加字段，向后兼容）。

   丢文本 **0**、跳转目标丢失 **0**、godot 无 `kind` **0**、unity 丢跳转 **0**。

### 边界（写清楚，避免被当成"能播了"）

- `condition` 仍是**字符串**：条件求值由 Unity 侧实现，工具不猜语义。
- 没有资源地址映射：assets 只有工具里的 ID/Path，Unity 侧要按 Addressables 规则映射。
- 没有菜单 UI / 立绘合成 / 存档运行时；这需要另开一个 Unity 工程。
- `timeline` 是线性操作序列；分支/菜单树由 `structure` + `nest` 表达，
  真正建树仍要播放器按 `structure.path` 归组。
