## 一、P1-1：界面「从剧本表导出」绕过了那道闸

### 症状

和 P0 一模一样，只是换了入口：

1. 上一轮导出过这一章 → 文件首行有生成标记；
2. 程序员在同一个 `.rpy` 里加了 `pause 0.5` / 一句台词 / `$ flag = True`；
3. 策划在表里改一句 → 界面「从剧本表导出」。

`apply_export` 报 `ok=True / written=True`，**程序员那三行全没了**。

### 为什么只有这条路漏

CLI 走 `compile.write_compiled`，它把 `source_path` / `source_text` 一起交给门禁；
界面走 `app.tables.export_table` → `apply_export`，**只交了 `merged_from`**。

而"原地覆盖 + 这一刀不是增量 → 拒写"这条判据必须先有 `source_text` 才进得去
（判据是 `source_text is not None and merging_onto(target, source) and
not merged_onto_target`）。少了它，只剩手工护栏在判 —— 而手工护栏按
"首行有没有生成标记"判，带标记的文件它一律放行（那正是"再导出一次"的正常路径）。

`export_table` 的**预检**（`evaluate_generation`）确实拿得到 `source_text`，
但它只查 `OPAQUE_LOST`（顶层语句会不会丢）——label 里的 `pause` / `$`
不在它的判据里，所以预检报 `blocking=[]`。

### 修法

| 位置 | 改动 |
|---|---|
| `app/tables.py` | 结果包里加 `source_path`（落盘那一步全靠它） |
| `app/tables.py` | `apply_export` 读源文并传 `source_text` / `source_path` 给 `write_generation` |

判据：`tests/test_table_export_inplace_guard.py` 前 4 条。

## 二、P1-2：回执说"改动 N 行"，不说**删了源文件里哪几行**

### 症状

用户清空某一拍的「立绘」列 → 导出：

```
增量补丁：改动 2 行，原文其余部分（含 default / init python / transform）逐字节保留
```

而源文件里那一行 `show ling happy` **没了**。用户的第一反应是
"我只改了一句台词，怎么少了一行 show？" —— 他得自己 diff 文件才知道发生了什么。

`changed_lines` 把三种完全不同的动作混成一个数：换一句台词、插一行、
**删掉源里一行**。

### 修法

- `patcher`：`_replace_matched`（拍内删行，清空某一列）与
  `_apply_sequence_edits`（整拍删除）都往 `removed_preview` 收集被删的原文
  （去缩进，最多 5 条）；
- `patch_export` 把它放进 `PatchResult.removed_preview`；
- `compile.merge_incrementally` / `write_compiled` 透传到 `CompileResult`；
- `cli._report_incremental` 打印：

```
增量补丁：改动 2 行，原文其余部分（…）逐字节保留
  其中**删掉了源文件里的这几行**（表里已经没有对应内容）：
    - show ling happy
```

- 界面那条路：`export_table` 的 `note` 里带一句
  `；其中删掉了源文件里 1 行（show ling happy）`，确认框直接看得见。

判据：`tests/test_table_export_inplace_guard.py::TestRemovedLinesAreNamed`（2 条）。

## 三、这轮排除的两个候选（探过，不是问题）

| 候选 | 实测 |
|---|---|
| 在**第一张卡之前**插一拍 | 台词正确落在 `label ch01:` **之后**，产物合法 |
| 把某一行的「章节」改成 `ch99` | 生成两个 label（原章少了那句、新章有那句），并明确报"增量未采用"，语义正确 |
| 把表里**所有行**删掉 | 退 2「剧本表为空」，源文件不动 |
| 真机 `pomodorro` 删第 28 行（L2b 的唯一 FAIL） | **能走增量**（"改动 8 行"，差异只有 1 段 delete + 首部标记）。L2b 那条 FAIL 是脚本自己的抖动，不是产品缺陷 |

探针留在 `tools/probe_table_edges.py`。
