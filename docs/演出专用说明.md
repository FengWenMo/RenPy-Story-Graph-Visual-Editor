# 演出专用版 · 使用说明（给文案 / 策划）

> 这一版和普通版只差三件事：**自带 Ren'Py 引擎**（能真跑演出）、
> **自带这个项目的规则与布局**（打开就能用）、**收到项目就自动打开**。
> 你不需要装 Python / Ren'Py / VSCode，也不需要会命令行。

---

## 一、第一次打开（三步）

1. **解压**：把发来的 `StoryGraph-Stage-…zip` 解压到硬盘上任意位置。
   ⚠ 不要直接在压缩包里双击 `StoryGraph.exe` —— 那样引擎目录不完整，
   「🎮 引擎试玩」会起不来。
2. **把项目文件夹放到工具旁边**：解压出来会有一个 `项目` 文件夹
   （里面是 `game/`），把它和 `StoryGraph.exe` 放在同一个目录里。
   - 也可以反过来：把工具解压进项目文件夹里（`StoryGraph.exe` 和 `game/`
     同级）。
   - 也可以什么都不放：直接双击 `StoryGraph.exe`，点「📁 打开项目」自己选。
3. **双击 `StoryGraph.exe`**。第一次打开会自动做两件事：
   - 打开旁边的项目（左侧「章节」树会列出一章章的文件）；
   - 检查项目里有没有工具配置：缺 `storygraph.rules.json`
     （卡片上「角色 / 服装 / 表情」下拉的候选）和
     布局（剧情图摆在哪）就用随包那份补上 —— **项目里已经有了就一个字都不动**。

> 工具的记忆功能：第二次打开会回到上次的项目 / 上次那一章 / 上次的界面摆法。
> 想空着打开：关掉工具再开，它不会乱动你的项目。

---

## 二、界面一分钟

```
┌ 顶部工具栏 ─────────────────────────────────────────────┐
│ 剧情结构页：章和章怎么串（导入章节 / 连线 / 自动布局）        │
│ 卡片页：这一章怎么演（一拍一张卡；顶上是工具栏，右下是控制台）  │
└─────────────────────────────────────────────────────────┘
左侧「章节」树：项目里所有能打开的章 —— 点一下就能看
```

最常用的两件事：

- **看 / 改某一章**：左侧章节树点它 → 进卡片页 → 一拍一张卡；
- **看这一章"真跑起来"是什么样**：卡片页工具栏「🎮 引擎试玩」。

---

## 三、「🎮 引擎试玩」怎么用（这一版的核心）

卡片页工具栏上有两个按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **🎮 引擎试玩** | 用真正的 Ren'Py 引擎，**从这一章开头**跑一遍 | 改完一场戏，想看完整演出效果 |
| **🎞 从这一拍试玩** | 直接落到**你正改的那一拍**（近似） | 只调这一拍，不想从头点 |

第一次点会等几秒（工具在后台准备一份"预览副本"，不会动你的项目）。
然后游戏窗口就出来了 —— 窗口标题是这个游戏的名字。**关掉游戏窗口就回到工具**，
工具这边一切照旧。

### 必须知道的两条

1. **引擎读的是硬盘上的 `.rpy`**，不是卡片内存里的内容。
   改完卡片请先点「⤓ 导出 .rpy」（或 `Ctrl+Shift+S`）再试玩；
   没导出就点试玩，工具会先提醒你（默认「取消，先去导出」）。
2. **「从这一拍」是近似预览**：它跳过了前情，前面几章用 `$` 设过的变量没有值，
   脚本一读就可能报错（那说明这一拍确实依赖前情，不是工具坏了）。
   想稳妥就从「🎮 引擎试玩」从章首跑。

### 和「🎬 演出预览」的区别

| | 🎬 演出预览 | 🎮 引擎试玩 |
|---|---|---|
| 谁在演 | 工具自己按卡片重画 | **真 Ren'Py 引擎** |
| 改一句看一眼 | 快（几乎立刻） | 要开一次游戏窗口 |
| 转场 / ATL 动画 / 特效 | ❌ 不真实 | ✅ 和游戏里一模一样 |
| 项目自定义界面 / 小游戏 / 菜单 | ❌ 不跑 | ✅ 真跑 |
| 适合 | 快速校对台词、背景、立绘 | 验收演出效果 |

## 四、随包的东西（别删、别改）

| 目录 / 文件 | 是什么 | 能删吗 |
|---|---|---|
| `renpy_sdk/` | 完整的 Ren'Py 引擎（约 330 MB） | 删了「引擎试玩」就用不了 |
| `项目预设/` | 这个项目的规则（角色/服装/表情候选）与布局 | 删了以后项目缺配置时补不回来 |
| `项目/`（你放进去的） | 你的**完整项目文件夹** | 删了就没内容可编 |
| `故事…说明.md` | 本文件 | 可删，但建议留着 |

> **唯一真源是项目里的 `.rpy` 文件**。工具不会替你"改回"什么，也不会把项目
> 上传到任何地方；所有预览缓存都在
> `%LOCALAPPDATA%\StoryGraph\engine_preview\` 里，删掉只是下次慢一点。

## 五、出问题怎么办

| 现象 | 先看什么 | 怎么办 |
|---|---|---|
| 双击 `StoryGraph.exe` 没反应 / 一闪就没 | 有没有解压完整；杀毒软件有没有隔离文件 | 重新解压一次；把整个文件夹加进杀毒白名单；再看 `%LOCALAPPDATA%\StoryGraph\crash.log` |
| 「引擎试玩」提示"没找到内置引擎" | `StoryGraph.exe` 旁边有没有 `renpy_sdk\` | 多半是解压不完整 / 被杀毒隔离，重新解压；还不行把整包发回 |
| 引擎窗口出来了但是黑屏 | 稍等 2~3 秒（第一次要加载图片 / 音频）；或看工具右下控制台 | 还黑就把控制台里 `[引擎]` 开头那几行截图发回 |
| 引擎起来又马上退出 | 工具会弹"引擎退出了"，里面是引擎自己的报错 | 把弹窗内容 + 控制台 `[引擎]` 几行一起发回 |
| 游戏窗口找不到了 | 看任务栏；有时候被全屏工具挡住 | `Alt+Tab` 切回来；关掉工具也会把引擎一起关掉 |
| 试玩看到的是旧台词 | 引擎读的是磁盘 `.rpy` | 回卡片页「⤓ 导出 .rpy」再试玩 |
| 卡片上「角色 / 服装 / 表情」下拉是空的 | 项目里 `storygraph.rules.json` 在不在 | 关掉工具重开（会自动补预设）；或从 `项目预设/` 手动复制一份到项目根目录 |

给开发者反馈时，最有用的是三样：

1. 工具右下控制台里所有 `[引擎]` / `[预设]` 开头的行；
2. 弹窗的文字（可以直接截图）；
3. `%LOCALAPPDATA%\StoryGraph\engine_preview\` 下最近那个目录里的
   `log.txt` / `errors.txt`（有 `traceback.txt` 就一起带上）。

## 六、和"标准版"的区别

| | 标准版 | 演出专用版（本包） |
|---|---|---|
| 包体 | 约 70 MB | 约 300 MB 起步（自带完整引擎） |
| 装 Ren'Py / Python | 不需要 | 不需要 |
| 「🎬 演出预览」 | ✅ | ✅ |
| 「🎮 引擎试玩」（真演出） | ❌（提示去用演出专用版） | ✅ |
| 打开旁边的项目就自动打开 | ❌ | ✅ |
| 项目缺规则 / 布局时自动补 | ❌（不碰用户项目） | ✅（只补缺，不覆盖） |

> 工具对**项目文件**的态度两版完全一样：只写你让它写的那一份 `.rpy`
> （导出前还有门禁和预览），绝不偷偷改别的文件。

## 七、版本信息

- 工具版本 / 打包日期 / 内含 Ren'Py 版本 / 预设指纹：见同目录
  `演出专用版.txt`（纯文本，出问题时可整份发回）。
- 换新版本时：**项目文件夹原样留着**，把工具文件夹换成新的即可
  （项目预设只补缺；你的规则 / 布局不会被覆盖）。
