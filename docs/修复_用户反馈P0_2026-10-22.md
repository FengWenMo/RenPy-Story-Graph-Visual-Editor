### 1. 预览（P0-1）

`open_stage_preview()` 现在把 `_loaded_idx` 传给 `open_preview()`；
`StagePreviewWindow` 接受 `start_index`，`_show_initial_frame()` 用
`self.idx` 而不是写死的 0。

判据：`tests/test_stage_preview_start.py`（8 条，含越界 / 负数 / 垃圾值 / 空 frames）。

### 2. 同一个 `.rpy` 的第二个 label（P0-2）

- `EditorSession.load(path, label=None)` 多一个**聚焦 label**，不改变“载入整个文件”；
- 新增 `label_names()` / `index_of_label(label)`；
- `MainWindowQt.load_script(..., label=...)` 用 `index_of_label()` 定位第一拍；
- `_on_node_open()` 传 `node.label_name`；
- `_sync_graph_highlight()` 同时匹配文件与 label，不再永远高亮第一个；
- 左栏新增 label 下拉；卡片面包屑显示 `剧情结构 › 文件 › label`；
- 翻到别的 label 时，下拉 / 面包屑 / 图上高亮一起变。

### 3. 无源节点的四种状态（P0-3）

`NodeEditMixin._source_info(node)` 返回：

```text
BOUND    有 file_path，文件存在          → 主按钮「打开本章剧本」
FOUND    无 file_path，项目里找得到声明  → 主按钮「导入并绑定源文件」
MANUAL   无 file_path，项目里也找不到    → 主按钮「给这个节点建/绑源文件」
MISSING  有 file_path，但磁盘上没了      → 主按钮「给这个节点建/绑源文件」
```

修复动作：

- **FOUND**：确认后导入声明它的 `.rpy`，同名节点会被 GraphBuilder 更新
  `file_path`（不是新建一个重复节点）；
- **MANUAL**：新建 `.rpy`（默认 `<项目>/game/<label>.rpy`）或绑定已有文件；
  绑定前会检查文件里**真的有这个 label**，避免指错；
- **MISSING**：在原路径新建最小骨架，或重新定位到别的文件。

所有路径最终都走 `_import_and_open()`：导入 → 找回同名节点 → 载入该 label →
高亮节点。

### 4. 在工具内新建第二个 label（P1-1）

两个入口：

1. `➕ 新章节` → 章节名 → 在「已导入文件」下拉里选一个 `.rpy`，或点
   「选已有…」；创建时往那个文件末尾追加 `label 名:` + `return`；
2. 右键任意有源节点 → **「在本文件新建 label…」**：文件已确定，只问 label 名；
   写完直接在当前图里加节点、打开新 label 第一拍。

底层仍是 `_write_new_chapter()`：保留 BOM / CRLF，文件原有字节不动，
同名 label 拒绝。

### 5. 点号 label（P1-6）

- `dialogs.valid_label()`：`main.route` / `side.choice.ending` 通过；
  `main..route` / `.route` / `main.` 拒绝；
- `discover._LABEL_RE` / `_REF_RE`：声明与 `jump/call` 引用都支持点号分段。

## 二、用户验收步骤

### A. 预览当前拍

1. 打开一个 20 拍以上的章节，翻到第 10 拍；
2. 点「🎬 演出预览」；
3. 预览应直接显示第 10 拍（标题/底栏不再从第 1 拍开始）。

### B. 同一文件第二个 label

1. 右键 `ch01` 节点 →「在本文件新建 label…」→ 输入 `ch01_extra`；
2. 应直接进入卡片页，面包屑是 `ch01.rpy › ch01_extra`；
3. 左栏 label 下拉应在 `ch01` / `ch01_extra` 之间切换；
4. 回剧情结构，点 `ch01_extra` 节点，应打开它的第一拍，而不是 `ch01` 第一拍。

### C. 无源节点

1. 新建一个“只画结构”的节点（新建章节时把「写入文件」留空）；
2. 选中它，右栏应显示「手工节点，还没有源文件」，主按钮是
   「🩹 给这个节点建/绑源文件」；
3. 点主按钮 →「新建 .rpy…」→ 确认默认路径；
4. 节点应变成有源，卡片页直接打开这个 label；
5. 找一个“别的章节 jump 过来、但文件还没导入”的占位块：主按钮应变成
   「🔗 导入并绑定源文件」，点一下就能导入并打开。

### D. 点号 label

1. 新建章节名填 `main.route`，应能创建（不再提示“不合法”）；
2. 在另一个文件里写 `jump main.route`，用「补全相关章节」应能找到它。
