## 0. 结论

**增量这条路的保真度是真的：一个字不改的往返，55 个文件内容 100% 逐字节还原；改一句只动那一行。**

**但有一个 P0 级别的静默失效：从表格改「说话人」，工具报成功、退出码 0，脚本里一个字都没变。四个人人都要做的操作里，只有这一项是坏的。**

再收紧一句：这不是"保真度不够"，是"有一格改了不算数"。

## 3. 两个 P0

### P0-1：从表格改「说话人」，静默不生效

| 路径 | 结果 |
|---|---|
| **界面改说话人**（卡片页下拉） | ✅ `jc` → `yhj`，只改那一行 |
| **表格改说话人**（Excel 改一格 → `xlsx2rpy --source`） | ❌ 产物仍是 `jc`，报告写「**改动 0 行**」，退出码 **0** |

4 个章节 **4/4 复现**（`chapter1_2` `chapter0_0` `pomodorro` `script`）。

判别实验最能说明问题：

| 改什么 | 产物 |
|---|---|
| 只改说话人 | 一个字节没动，报告"改动 0 行" |
| 只改台词 | 只改那一行 ✅ |
| 改说话人 **+** 改台词 | 「增量未采用（1 处新增内容没能落进产物）→ 已按全量生成」 |

**根因**（读代码定位，未改动）：
`patcher._line_key()` 给台词算的配对键是 `('say', 说话人)`，**说话人必须一样才允许换正文**。
`ignore_speaker=True`（句位配对，允许换说话人）只在 `trust_ranges=True` 时开。
而 `trust_ranges` 只有 `app/session_export.py:580` 设置 —— 那是**界面的导出路径**。
CLI 的 `--source` 路径不带这个标志，于是：

> 新行 `yhj "…"` 与原文 `jc "…"` 的键不同 → 配不上 → 按 §"认不出一律保守"处理 → **原文一个字不动** → `changed=0`。

配对失败本该出声（`unlanded`），但这条路上没进"新增内容没落地"那条退回全量的判据，所以既不写、也不报、也不退回 —— 三条路都没走，落在缝里。

**为什么这条是 P0**：表里写着 `yhj`，脚本里是 `jc`，工具说"成功"。策划改完交付，配音/形象全对不上，而且没有任何信号。

### P0-2：门禁拿不到上下文，会把好产物判成坏

`screens.rpy` 往返 → 门禁拒绝写入，理由：

```
[block] ENGINE_PARSE_ERROR（整体）：引擎读不了这份产物（SDK lint）：
        引擎 lint 期间抛异常（产物加载即崩）：NameError: name 'button_tile' is not defined
```

实际情况：

| 项 | 事实 |
|---|---|
| `button_tile` 在 `screens.rpy` 里 | **根本不存在** |
| 它在哪 | `gui.rpy:151` → `define gui.button_tile = False` |
| 产物内容 | 3938 → 3940 行，**0 删除**，只多 2 行标记 |
| 补上 `gui.rpy` 再跑 lint | **0 条语法错 / 0 条 NameError**，解析出 31 个 screen |

**所以产物是好的，门禁的临时工程里缺了 `gui.rpy`。**

这不是"保守得过分"，是**判据缺上下文**：工具用"只放这一份产物"的最小工程去问一个必然依赖别的文件的问题。代价是用户看到"引擎读不了这份产物"这种最吓人的一句话，而它其实没事。

按单点编辑的 P0 判据（只动 1 段、其余不变）：**13/20 = 65%**。把 P0-1 那 4 例摘掉，是 **13/16 = 81%**。

## 7. 该肯定的地方（不是客套，是判据）

1. **配对失败默认保守**：`_line_key` 认不出就"原文一个字不动"。P0-1 的根因正是这条纪律执行得**太彻底** —— 它不是草率，是过度谨慎加上漏了一个出声的口子。
2. **门禁真的会拦**：`screens.rpy`、`pomodorro` 删除两处都被拦住了。拦错的只有 P0-2（缺上下文），拦对的有 1 处。
3. **幂等是真的**：54/54。
4. **编码形态零失误**：BOM、CRLF、末尾无换行，55 个文件全部还原。
5. **报告会说"改动 N 行"**，不是笼统的"成功"。

### 10.4 顺带修掉的真缺陷（pomodorro 三连的第二根）

`_recover_ranges_for_groups` 把**组内下标**当全局下标写进 `inserted_out`。
多 label 章节（pomodorro 有 10 个）里，新卡片会被当成"替换"、原文那一行被顶掉，
再被 `_verify_patch` 否掉 → 退回全量。改成 `{id(beat): 全局下标}` 之后，
pomodorro 插入一拍从"动了 60 段"变成"插 2 行"。
