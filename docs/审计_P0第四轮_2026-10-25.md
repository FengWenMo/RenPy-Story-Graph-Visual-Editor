## 三、新 P0：**含自定义语句的拍，改台词静默不落盘**

### 最小复现

```rpy
label start:
    mycue intensity=3 layer=camera     ← 自定义语句（未建模）
    e "台词"
    return
```

两句合并成**一拍**（`raw='mycue intensity=3 layer=camera'` + `text='台词'`）。
把 Text 改成 `改过的` → 导出 `ok=True`，**零 diff**（文件一个字节没动）。

### 对照（都不命中）

| 前一行是什么 | 改台词 |
|---|---|
| `$ x = 1` | ✅ 只动一行 |
| `python:` 块 | ✅ |
| `hide screen x` | ✅ |
| `# 注释` | ✅ |
| （台词在 if 里） | ✅ |
| 真机 `hide screen map` + 台词 | ✅（36 拍实测） |
| **自定义语句 `mycue …`** | ❌ **零 diff** |

### 影响

用户画像里明确要"自定义 transform / 自定义模块"。凡是**自定义语句与台词连着写**
（会合并成一拍）的地方，在卡片/表格里改那句台词 → 导出成功、内容没变。
改别的字段（删拍、改说话人）也要逐条验。

### 根因方向

`storygraph/story/patcher.py` 对"拍里含工具不认识的语句"走保守通道：
`_rewrite_line` 的"保留原文"分支把**整拍**判成"不许替换"，于是同一拍里的
say 行也没替换。应该是：**opaque 行原样保留，say 行照常替换**（只动该动的行）。

### 判据

```python
src = 'label start:\n    mycue intensity=3 layer=camera\n    e "台词"\n    return\n'
# 改 Text → 导出后必须是：
#     mycue intensity=3 layer=camera   ← 原样
#     e "改过的"                        ← 只改这一行
```

## 四、判据校准（本轮误报，别当 bug 修）

1. **tab 缩进导出被拒** → Ren'Py 自己禁 tab（lint："Tab characters are not allowed"）。
   工具拦得对。
2. **`menu "标题":` 改标题被拒** → 那个写法本身非法（Ren'Py 的 menu 标题是
   `menu:` 下的**无冒号字符串行**）。用真机合法写法重测全部通过。
   顺带确认：补丁生成的 `menu "新标题":` 会被 SDK lint 打回（`expected ':'`），
   而渲染器生成的 `menu:` + `"新标题"` 是合法的 —— 别"修"错方向。
3. **表格改说话人不生效** → 我脚本漏了 `wb.save`。修完是 ✅。
4. **改选项体台词插入新行** → 那拍是代码拍（`$ renpy.block_rollback()`），
   给它加 Text = 新增一句台词，正确。
5. **`fields['Position']` / `fields['CodeBlock']` 改了不生效** → 前者真实路径是
   立绘卡，后者是自定义语句的参数格（不是 python 通道）。属用错字段。

## 七、总判据（建议固化进测试）
