## 1. 窗口骨架

### 1.1 画布与栅格

| 项 | 值 |
|---|---|
| 设计基准窗口 | 1440 × 900（100% 缩放，96dpi） |
| 最小可用窗口 | 980 × 700（小于此时触发降级，见 §1.3） |
| 栅格基线 | **8px**；组件内部可用 4px（半格） |
| 外边距 | 左右 16px，上下 12px |
| 分区间距 | 16px；分区内元素间距 8px；紧密元素 4px |

### 1.2 分区与精确尺寸（1440×900）

│   C2 说话人行                                                            │
│   C3 台词区                                                              │
│   C4 立绘区（网格）                                                      │

**滚动策略（关键体验决策）**：
- `C1–C4`（这一拍 / 说话人 / 台词 / 立绘）必须在 **1440×900 下不滚动即可完整看到**——这是用户 90% 的操作面。
- `C5–C8` 允许随内容滚动；`C8` 默认收起。
- 右栏用 **Canvas + 内部 Frame + 鼠标滚轮** 实现滚动（tkinter 的 Frame 不支持滚动）。

### 1.3 降级（窗口 < 980 宽）

| 触发 | 降级行为 |
|---|---|
| 宽 < 980 | 左栏 Beat 列表宽度 340 → 260；立绘网格每行 5 → 3 张 |
| 宽 < 860 | 立绘卡片切「紧凑档」：图区 88×118 → 64×86，卡片 76×132，隐藏位置 chip（改到选中后编辑） |
| 高 < 700 | C5 继承提示条收起为一行（省略详情，tooltip 保留）；高级区强制收起 |

### 1.4 tkinter 实现策略（圆角 / 阴影的取舍）

tkinter **没有**圆角、阴影、CSS 变换。方案：

| 视觉需求 | 实现 |
|---|---|
| 圆角卡片 | 立绘卡用 **`tk.Canvas`（100×176）** 绘制圆角矩形 `create_polygon`（平滑）或近似 `create_arc` 组合；事件绑在 Canvas 上。**卡片是唯一值得用 Canvas 的组件**（它同时要装图、文字、徽标、状态）。 |
| 阴影 | **不用阴影**。用 0.5px 描边 + 底色差表达层级（扁平）。阴影在 tkinter 里要靠多 Frame 叠加，收益低、易出渲染瑕疵。 |
| 悬停动效 | 只改 `bg` / `highlightbackground`（颜色），**不改几何**，避免重新布局抖动。 |
| 圆角 chip | Canvas 或 `Label` + 直角（chip 用 **全圆角** 是理想；tkinter 降级为直角 + 1px 描边，视觉差可接受，因为 chip 很小）。 |
| 骨架呼吸 | `after(400, ...)` 在两个底色间切换，**最多 3 次**后停在静态色。 |

### 3.3 SpriteCard（立绘卡）— 100 × 176（最核心组件）

用 `tk.Canvas(100, 176, highlightthickness=0)` 绘制：

| # | 元素 | 坐标（相对卡片） | 规格 |
|---|---|---|---|
| 1 | 卡片底 | (0,0)-(100,176) | 圆角 8，`bg.card`，描边 `stroke.hair` |
| 2 | 图区 | x=6, y=6, w=88, h=118 | **尺寸恒定**（骨架同尺寸）；图按 3:4 等比裁切居中，不压扁 |

| 6 | 右上角 ✕ | (78,6)-(94,22) | 16×16 视觉 / **24×24 命中**；默认隐藏，**卡片 hover 时才显示**；色 `state.error` |
| 7 | 选中标记 | (84,84) 附近右上 | 12×12 `✓` 圆底 `brand.primary` + 白勾 |
| 8 | 左边条（说话态） | x=0, y=0, w=3, h=176 | `brand.primary`（说话中的立绘，扫一眼就知道谁在讲） |
| 9 | 缺图占位 | 图区中心 | tag 首字大写，28px，`text.graphic #9E9E9E`；图区底部叠 `⚠ 缺图` 徽标（`state.warningBg` 底 + `state.warning` 字，8pt） |
| 10 | 异常徽标 | 图区底部（与缺图互斥优先级更高） | `⚠ 同 tag 多条`，`state.warning` |

| 状态 | 卡片底 | 描边 | 其它 |
|---|---|---|---|
| 默认 | `bg.card` | `hair #E0E0E0` | — |
| 悬停 | `bg.cardHover` | `strong #90CAF9` | ✕ 淡入（150ms） |
| 选中 | `brand.subtle` | **2px `brand.primary`** | ✓ 标记显示 |
| 说话中 | 同默认/选中 | + 左边条 3px 主色 | 名字加粗 + `▶ 说话` |
| 加载中 | 图区 `bg.skeleton` ↔ `bg.skeletonAlt` 呼吸 ×3 | — | **名字与 chip 立即渲染真值**（不等图） |
| 缺图 | 图区 `#FAFAFA` + 首字占位 | — | ⚠ 徽标；**卡片仍可点选/改表情/删除** |
| 禁用 | 底 `#F5F5F5`，字 `#9E9E9E` | — | 不可点（用于只读预览场景） |

**交互**
- 单击卡片 = 选中（单选；再点一次不取消，避免误操作丢失选中）。
- 双击卡片 = 打开资产选择器（等价于 🔍）。
- chip 单击 = 直接切换（表情/位置），**1 次点击完成**。
- ✕ = 删除 + Toast 撤销（8 秒）。
- 键盘：`Tab` 进入网格 → `←→↑↓` 在卡片间移动 → `Enter` 选中 → `Delete` 删除（可撤销）。

## 6. 任务流（逐步界面反馈）

### T1 通读校对（最高频）

1. `Alt+↓` 或点顶部「下一句 ▶」→ 右栏字段整体替换（150ms 内），左栏列表 `see()` 滚到当前行。
2. 立绘卡：**名字与 chip 立即出现**（不等图），图区显示骨架 → 图到后覆盖（**不跳布局**）。
3. 说话中的立绘卡：左边条 3px 主色 + `▶ 说话`。

### T2 改第二张立绘的表情

1. 目光落在立绘网格（第一屏内，无需滚动）。
2. **直接点第二张卡上的表情 chip** → 下拉/循环切换。
3. 卡片 chip 变选中（✓ + 主色描边），Toast：`已切换到「生气」`。
4. 缩略图异步换成新表情的图（骨架占位，不跳）。

**总交互：1 次点击**（当前：滚到行 → 手填 → 可能填错入口 = 2–3 次且易错）。

### T3 添加 / 删除立绘

- 添加：点网格末尾虚线卡 → 打开资产选择器（默认跳到当前值、滚到它、显示预览）→ 确定 → 新卡出现在网格末尾。
- 删除：hover 卡片 → ✕ 出现 → 点击 → 卡片消失 + Toast「已删除立绘「ling」· 撤销」→ 8 秒内可撤销（顺序与索引正确恢复）。

### T4 批量改说话人

- 左栏「参与角色」多选 → 回车轮流说话。当前实现保留；**补**：每次回车后 Toast 显示「下一句说话人：{名字}」，避免不知道轮到谁。

## 7. 极端与边界

| 场景 | 处理 |
|---|---|
| 立绘名超长（> 12 字符） | 名字条截断 `…` + tooltip 全名；**卡片尺寸不变** |
| 一拍 10+ 张立绘 | 网格最多 2 行（360 高）后内部滚动；副信息显示「共 12 张」 |
| 立绘图全部缺失 | 全部显示首字占位 + `⚠ 缺图`；**卡片仍可点选/改表情/删除**（不阻断编辑） |
| 同一 tag 多条且位置不同 | 卡上 `⚠ 同 tag 多条` + tooltip 说明「Ren'Py 中同 tag 只会有一个实例」 |
| 无角色 / 无台词 | 说话人 chip 提示 `⚠ 未登记`；台词空时占位「（留空＝纯舞台指令）」 |
| 台词超长（> 200 字） | 字数统计转 `state.warning`：「128 字」→「**214 字**（超出单屏建议）」 |
| 窗口 980×700（最小） | 见 §1.3 降级：卡片紧凑档、每行 3 张、继承条压缩 |
| 无 Pillow | 缩略图走 `tk.PhotoImage`（png/gif）；其余格式显示首字占位 + `⚠ 缺图`，**不报错** |
| 图片解码失败 | 骨架停在静态 + `⚠ 无法预览`，卡片其余部分正常 |
| 首句 / 末句 | 翻页按钮禁用态 + tooltip 说明 |

## 8. 无障碍

### 焦点顺序（Tab）

`A 章节下拉 → A 跳到开头 → A 整章改名 → [翻页已并入 A] → B1 Beat 列表 → B2 参与角色 → C2 说话人 → C3 台词 → C4 立绘卡（逐张）→ 各卡 chip → 各卡 ✕ → AddCard → C6 条件 → C7 动作条 → C8 高级（展开后逐字段）→ D 底部按钮`

### 键盘映射

| 键 | 行为 |
|---|---|
| `Enter` | 下一句 |
| `Alt+↓` / `Alt+↑` | 下一句 / 上一句 |
| `Ctrl+Enter` | 应用并下一句 |
| `Tab` / `Shift+Tab` | 焦点前后 |
| `←→↑↓`（焦点在网格内） | 卡片间移动 |
| `Enter`（焦点在卡上） | 选中该卡 |
| `←→`（焦点在卡内 chip 上） | 切换表情 / 位置 |
| `Delete`（焦点在卡上） | 删除 + 可撤销 |
| `Esc` | 关闭弹窗 / 取消当前编辑 |

### 达标项

- **对比度**：正文 ≥ 4.5:1（表中已逐项标注）；`text.graphic #9E9E9E` **仅限图形**。
- **不靠颜色单编码**：选中 = 描边 + ✓；说话 = 文字 + 左边条；错误 = ⚠ + 文字。
- **焦点可见**：`stroke.focus` = 2px `#1976D2` + offset 2px，**所有可交互元素**。
- **命中区**：按钮 ≥ 28 高；icon 24×24；chip ≥ 24 高；卡片 100×176。
- **动效**：`prefers-reduced-motion` 等价开关（配置项「减少动效」）→ 骨架静态、hover 无过渡。
- **字号下限** 8pt（11px）；支持系统 DPI 缩放（tkinter：`scaling` 设置）。
