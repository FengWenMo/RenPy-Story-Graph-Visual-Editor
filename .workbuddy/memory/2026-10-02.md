## 审查发现的真问题（面试会被问穿的）

1. **双 IR 并存**：`core.statement.Statement` 是结构化 IR，但
   `graph.models.Node.operations` 仍存**裸代码字符串**；两条写入路径
   （parser `build_from_statements` vs `_extract_edges`），下游靠正则反解
   （`core/utils.py`、`graph/analysis.py`、`pipeline/renpy_exporter.py`）
2. **两套 .rpy 生成器**：`pipeline/renpy_exporter.export_to_renpy(graph)`
   与 `story/beat_render.render_beats_to_rpy(beats)` 规则链完全独立
3. **静默失败偏多**：321 个 except 里 **99 个 body 只有 pass**（31%）；
   全项目 **196 处 `# noqa: BLE001`**（main_window 50 / editor 35）
4. **事件总线 0 订阅者**：`assets/asset_events.py` 402 行的
   `AssetEventBus` 只有 publish（`asset_engine.py:667`），业务代码从没 `.subscribe()`
5. **上帝对象**：`app/editor.EditorSession` 70 方法 / 1812 行；
   `ui_qt/main_window.py` 3354 行（`MainWindowQt` 117 方法 + `BeatCardEditor` 32 方法同居）
6. **git 历史是硬伤**：只有 16 个 commit，message 全是「半成品」「ai修改1」
   「修改2」「检查点」——其中一条直接写着 AI，面试官会当场追问
