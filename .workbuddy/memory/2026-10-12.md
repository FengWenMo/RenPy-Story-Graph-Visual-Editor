### 实测确认的硬事实（临时探针 `%TEMP%/sg_teach_probe*.py`，只读、未写盘）

- **每张参数卡 = 表格里一列**：`build_declaration` 对 `params` **无条件**生成 column，
  与 `kind` 无关。→ 语句头那一格（如 `show`）建成"固定关键字"卡，会让表格多出一列 `name="show"`。
- **「剧本里怎么写」必须是合法标识符**（`^[A-Za-z_][A-Za-z0-9_]*$`）。填中文 → 该行被丢弃，
  报 `参数名 "角色" 不是合法标识符 —— 这一行没写进声明`（只在左栏预览区显示 ⚠）。
  **中文只能填在「表格那一列显示什么」**（生成 `label`）。
  实测正确产物：`[{"name":"show"},{"name":"speaker","label":"角色"},
  {"name":"outfit","label":"服装","choices":["swim_suit","uniform"]}]`，warnings 空。
- **口诀：剧本里怎么写填英文/内部名，表格那一列显示什么填中文。**
- **试切与列名合法性是两套闸门**：`pattern` 覆盖**整行（含语句头）** —— 不建 head 卡，
  第一格会把 head 吃掉 → 试切必红；反之试切 ok **也不代表** columns 合法。
- 候选值可以写中文（`show 林月见 泳装` 试切 ok）。
- **`suggest_shape()`（V2-2 反推）尚未接进这个弹窗**（grep `dialog_learn.py` 零命中）→
  "左栏点一行自动带出参数"目前**不成立**，参数须手填。属 V2-2 待并入项。

## 追加：修了两个确凿 bug（用户第二轮报"依旧切不上 + 回车按了没反应"）

### 根因（offscreen + 真 Qt 实测拿到的证据）
1. **`ParamCard` 里两个控件叠在同一个网格格**：`self.body.addWidget(self._limit, 1, 1)`
   —— 而 `(1,1)` 已经是「剧本里怎么写」的输入框（`field(1, ..., self._name)`）。
   渲染出来是"输入框里套着一个复选框"，点下去命中**上层那个** → 那一格根本填不进去。
   用户说的"按了没反应"就是它。
2. **候选值输入框的回车会把整个弹窗按掉**：`QLineEdit` 收到 Return 是 `event->ignore()`
   （Qt 专为"对话框里回车 = 确定"设计的），事件冒到 `QDialog` 点了 autoDefault 的 Ok →
   实测 `chips='abc'` 且 `弹窗还开着=False result=1`。
   危险在于 `learn_custom_statement` 里 `exec()==Accepted` 的下一句就是
   `declare_statement`（**写盘**）—— 等于"在候选值框里按一下回车就写了 rules.json"。

### 修复
- `ui_qt/param_cards.py`：`_group` → `(0,2)`（与「这一格是」同排）、`_limit` → `(2,0)`
  （与候选值同排）、`_choices` 仍 `(2,2)`。**行数不变**。
- `ui_qt/param_cards.py` `ChipEdit`：加 `self._edit.installEventFilter(self)` +
  `eventFilter()` 拦 `Key_Return/Key_Enter` → `_commit()` + `event.accept()` + `return True`。
- 新判据 2 条（`tests/test_custom_statement_entry.py` ⑥ 段）：
  `test_no_two_widgets_share_a_grid_cell_in_a_param_card`（扫网格，写成不变量）、
  `test_chip_edit_return_does_not_close_the_dialog`。
- **验收**：`tests/test_custom_statement_entry.py` **44 passed / 3.75s**；
  offscreen 渲染确认「剧本里怎么写」输入框已可见可填。

### 用户"依旧切不上"的正解（是用法，不是 bug）
`authoring/pattern.match_line` 的 pattern **覆盖整行（含语句头）** —— 用户三张卡是
choice/choice/choice，**没有 keyword `show` 那一格** → 第一格把 `show` 吃掉，
第二格 choice(候选=swim_suit) 撞上 `lan` 直接失败。
→ 必须把语句头也建成一张「固定关键字」卡：`add_param('show','','',kind='keyword')`
（现有判据 `test_the_cut_view_shows_what_each_cell_ate` 正是这个写法）。
另：他的三张卡「剧本里怎么写」**全是空的**（被复选框盖住没填进去），
列名是从「表格那一列显示什么」回填的 —— 这也是重叠 bug 的连带后果。

### 还发现（未改，待用户拍板）
- ⚠ **同类风险**：弹窗里 `self.name`（语句名）/ `self.sample`（试切样例）等 QLineEdit
  按回车**同样**触发 accept → 直接写盘。"粘一行剧本按回车想试切"就会关窗 + 写盘。
- 「从这些里选」不给候选值时，`pattern.problems_of` 已有话说（"要么给候选值，
  要么挂一个词组"），但界面**不显示** —— 建议显示到试切区，正好治这次的困惑。

## 追加二：第三轮（用户报 4 个问题）——2 个真 bug + 1 个假成功 + 1 个新功能

### ① 那个"点不动的空下拉"（P0，已修）
`ParamList.add_param` 里补词组那段被 `if self._groups:` 包着 —— **项目没声明任何词组时
`_groups` 为空**，新卡的下拉**一项都没有**（实测 `_group.count() == 0`）。
修：无条件 `clear()` + 补 `（不挂词组）` 兜底项。

### ② 切分"假成功"（P0，已修）
`authoring/pattern._tokens` 无空格分支里是 `out.append(text[i]); i += 1` —— **逐字切**。
后果：试切只写 `show` → 切成 `s,h,o,w`，**恰好填满 4 个格子**，界面显示
"切出来是这样：s（固定）｜h（角色）｜o（服装）｜w（表情）—— 共 4 格"。
一个**假成功**，与函数自己的注释（"切不出来就不硬切"）直接矛盾。
修：改成"把切不出候选的连续字攒成一段"（`show` → 1 个词 → 如实报"切不上"）。

### ③ 回车（P1，已修）
- 弹窗底部按钮 `setAutoDefault(False)` —— 否则**任何输入框里回车 = accept() = 写盘**。
- `dialog_learn.eventFilter`：普通输入框回车 = `focusNextChild()`（一路往下填）；
  `sample`（真实剧本行）回车 = **直接试切**。
- `ChipEdit._commit` 改成**一次收下所有**值，分隔符与后端 `parse_choices` 同一套
  （`，,、;；|` 与空白）→ "粘一大段 / 粘多行"都行。
- ⚠ **离屏复现不出"候选值只能填一个"**（`QTest` 连加 3 个都成功、焦点不跑、
  3 个 chip 在 240px 宽也不被裁）→ 待用户在真实环境复测。

### ④ 新功能：候选值**从项目里白拿**（用户核心诉求）
用户原话："我的真实项目内有无数个表情！我不可能将它们一个个输入进去！……
能够自动导入相关类别（当我说这是表情的时候）"。

- 新纯函数 `authoring/learn_statement.choice_sources(project_root, head='')`
  → `[{'key','label','values','source','count'}]`，三路来源：
  **① 立绘属性 · 引擎自己分的组**（`engine_facts.groups_of`，跨 tag 合并去重）
  **② 角色表** **③ 项目里真正用过的值**（`suggest_shape` 的 choices）。
  ⚠ **工具不猜"这格是不是表情"**（不变量 9）—— 只把来源摆出来，点哪个由人定。
- UI：`ParamCard` 卡头加「⚡ 导入候选」（只在 `kind == 'choice'` 时露出），
  `QMenu` 列出来源，选中即 `ChipEdit.add_values()` 追加 + 自动勾上"只能填这些"。
  来源由弹窗注入 `ParamList(sources_provider=...)` → **卡片不碰后端**。
- **真机验证**（`D:\千连万理\RenPyTest\sr_general`）：
  `立绘属性 · expressions（68 个）` / `outfit（7 个）` / `未分组（1 个）` /
  `角色表（28 个）` / `项目里用过的值（show）`；空项目 → `[]`（不瞎给）。
