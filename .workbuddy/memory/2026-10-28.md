### ⭐ 第二个更隐蔽：构建环境渗进了交付物

在 Git Bash 里跑 PyInstaller，`PortableGit/mingw64/bin` 在 `PATH` 上 →
PyInstaller 顺着 PATH 把 **Git 自带的 OpenSSL** 收进包：
`libcrypto-3-x64.dll` / `libssl-3-x64.dll`（6.8 MB），
和 Python 自己的 `libcrypto-3.dll` 并存 = **两套 OpenSSL**，谁先加载取决于
DLL 搜索顺序 → 只会表现为"https 偶尔失败"。
spec 里加了 `drop_foreign_binaries()`：来源带 `portablegit`/`mingw64`/`msys64`
的 binary 一律剔掉**并打印剔了哪几个**。判据：重新打包后 `_internal` 里
只剩 `libcrypto-3.dll` / `libssl-3.dll`，selfcheck 四项仍全过。
