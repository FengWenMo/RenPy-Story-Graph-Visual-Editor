1. `git add -A && git commit -m wip`（先把当时的混合状态存档）
2. `git checkout stash@{0} -- .` 拉回上一轮成果
3. `git checkout stash@{0}^3 -- .` 补回未跟踪文件
4. 对 6 个消费者文件，取"存档提交里有本轮改动 + 上一轮标记都在"的版本
5. 对 `validate.py` / `build.py` / `cli.py` 以 stash 为基底**重新施加**本轮改动
   （stash 版本比存档提交多 `resolve_asset_path` / `menu_labels` 等上一轮成果）
6. `git reset --mixed 2d3be2d` 收拾干净的仓库状态（wip 提交留在 reflog 里作恢复点）

**教训**：长会话里必须 grep 复核"关键函数真的在文件里"，不能只信写入成功；
每次大改后跑全量测试是唯一可靠的锚点。
