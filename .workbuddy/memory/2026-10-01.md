## Qt 迁移第二阶段：块状编辑器（图视图）+ 主窗口双视图

用户澄清（原话）："我要改的是：tk做的一个块状编辑器+这个卡片界面！
不是让你只剩一个卡片界面" —— 所以图视图**必须**迁，不能只迁卡片。

### 先修"没应用上"

用户说"完全没用到，数据全是原样" → 根因：**`main.py` 仍开 tkinter 的
GraphView**，Qt 版只挂在 `python -m storygraph.main_qt` 上，用户平时
用 `main.py` 启动 → 看到的还是老界面。
修法：**`main.py` 默认走 Qt**（PySide6 不可用自动退回 tkinter；
`--tk` 强制旧版）。受控验证：`main()` 实际开出的窗口是
`ScriptTableEditorWindowQt` ✓
（顺带验证：改一拍台词/表情后导出，产物确实带上了改动 ✓）

### 块状编辑器（`ui_qt/graph_canvas.py`）

- QGraphicsScene/QGraphicsView：节点块（圆角矩形 + 章节名 + 代码预览）、
  连线（贝塞尔 + jump/call/menu 分色）
- 交互：滚轮缩放（Ctrl）、拖块、空白处中键/空格+左键平移、点选、
  双击、右键菜单
- 自动布局**复用** `storygraph/graph/layout.py`（与 tkinter 版同一份）
- **数据模型不动**：还是 `graph/models.py` 的 Graph/Node/Edge
- 图从哪来：`IncrementalRenPyAnalyzer().analyze(files, graph=None)`
  返回的第二个值就是建好的图（之前我一直把它丢了）

### 主窗口双视图

`main_window.py` 重构为：**中央 = 块状编辑器**，**右 dock = 卡片界面**，
左 dock = 章节/参与角色；工具栏 = 打开项目/重新扫描/自动布局/载入单章/
保存这一拍/导出/体检/预览/说明。

- 双击一个块 → 卡片界面载入那一章（用 node.file_path）
- 卡片正在编辑的章 → 图上对应块高亮（`highlight_node`）
- 右键菜单：在卡片里打开 / 设为当前 / 删除块（只改内存里的图）

### 踩坑（Qt 特有，重要）

**在 `paint()` 里抛异常 = 直接 segfault，没有任何 traceback**。
`painter.Antialiasing` 在 PySide6 里不存在（要写
`QPainter.RenderHint.Antialiasing`）→ 我在 NodeItem.paint 里写错 →
进程 139 直接死，日志只有一行退出码。排查手法：二分到"单独渲染一个
NodeItem"，立刻现形。**自定义 paint 必须用完整枚举路径，且别在 paint
里做可能抛异常的事。**

另一个：offscreen 截图中文变方块 → `QT_QPA_FONTDIR=C:/Windows/Fonts`。
