## 二、E2 第一切片：**引擎优先的候选与分组**

一句话目标：**"下拉里放什么"由引擎决定，人一个都不用填。**

### 改了什么

| 层 | 改动 |
|---|---|
| `core/engine_facts.py` | + `grouped_choices(facts, tag, rename)`：**组来自引擎**、值 = 引擎候选 ∩ 组成员（**保持引擎顺序**）、没归组的候选进兜底栏（**绝不丢词**）、`rename` **只改名** |

| `ui_qt/window_card.py` | 分组提供者改为**引擎优先**（原来"项目没声明就不装提供者"，现在"引擎有也装"） |

### 判据：`tests/test_engine_choices.py` **28 条**

- 组来自引擎 / 值保持引擎顺序 / **没归组的词不丢** / rename 只改 label；
- `rename_overlay` 认对象与 dict、**忽略 `options`**；
- `group_conflicts`：同组两个 → 冲突；跨组、单个 → 不算；
- `expression_groups_for`：**引擎优先时不需要符号表**、忽略声明里的 `options`、
  **`facts=None` 时老路一字不变**、引擎没给该 tag 时回退；
- `beat_group_conflicts`：`lan happy sad` 命中、`lan happy clothes2` 不算、没 facts 时不宣称；
- 会话：**采不到 ≠ 没有**（文件缺失 / **`probe_complete=False`** / JSON 坏 → 一律 `{}`）、
  缓存命中、**文件变了缓存自动失效**；
- **真机那 2 条**：拿 `sr_general` 的 `engine_facts.json` 直接喂进 E2 ——
  `grouped_choices('lan', {'outfit':'服装'})` 出「服装」栏且含 `clothes2`；
  `expression_groups_for('lan', None, [], facts)` 直接给出分组候选（共 ≥5 个值）。

## 四、⭐ 全量测试抓到我的一条真回归（已修）

**全量：3978 passed / 5 failed / 2 skipped（27:36）**。其中 **2 条是我引入的**：

```
tests/test_editor_session_mixin_contract.py::TestRequiresIsHonest::
    test_read_dependencies_are_declared[session_graph]
    test_no_dependency_is_unreachable[session_graph]
→ GraphSessionMixin 读到了这些宿主成员却没写进 REQUIRES：['_engine_facts_cache']
```

**根因**：`tests/test_editor_session_mixin_contract.py` 的 `_own_members()` 只把
**类体里声明的东西**算作"自己的"；凡"类体里没声明、却被 `self.X` **读**"的，一律当成
"宿主必须提供的依赖"（`self.X = ...` 是**写**，不算依赖 —— 判据分得很清楚）。
我的 `return self._engine_facts_cache` 是一次**读**，于是被判成依赖。

**修法（诚实的那种）**：**不是**往 `REQUIRES` 里塞 —— 那是撒谎（缓存是本 mixin 自己的状态）。
而是把 `_engine_facts_stamp` / `_engine_facts_cache` **声明成类属性**，
让守卫把它们算作 `own`。复跑（契约守卫 + E2 + 词组 + 引擎事实）**112 passed**，提交 `819e0d8`。

⚠ **教训**：本仓库的守卫经常"抓真东西"。**别为了让守卫变绿而改声明 —— 先问"它说的对不对"。**
另 3 条失败是沙箱批量删除守卫导致的环境问题（`TestPruneBounds` 单独跑 5 passed）。
