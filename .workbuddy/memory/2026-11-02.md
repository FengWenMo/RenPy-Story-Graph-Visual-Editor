## 引擎的判决（最小项目 + 真项目都实测）

    show lan happy      → 不报

⇒ 922 处 `show <tag> aa …` 在引擎里都是坏引用（`aa` 只在 `CC_OUTFIT_CYCLE`

## 新模块 `assets/engine_images.py`

`镜像 .rpy（不拷图）→ renpy.exe lint → 解析 "'X' is not an image." → 缓存`。
- 缓存存**用户级**目录（`.cache` 不可写 → 逐级回退到 AppData/Local/临时）；
- key 用 `_norm_root()`（剔控制字符 + Path 归一 + lower）—— 实测
  `str` 与 `Path` 会算出两个 hash；
- 失效 = 脚本指纹 + 图片数量；
- 只给**否定**证据（lint 只检查被 show 用到的名字）。

`_kick_engine_images()`（`load_assets` 末尾）：缓存新鲜→秒用；否则**起 daemon
线程**跑（14s），跑完下次打开生效。没 SDK 则静默空转。

提示优先级：**⓪ 引擎裁决（最硬，引用 lint 原话）** > 声明 > 写法 > 角色表 >
素材 > `init python` 定义 > 都没有。

真机：`lan aa happy` / `lan happy aa` 都报引擎原话；`lan close_happy happy` 不吭声；
`lan ba happy` 仍走声明层。**引擎压过 `init python` 的 `aa`**（用户问的正是这个）。
