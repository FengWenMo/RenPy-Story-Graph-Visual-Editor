并行会话把 `docs/终极方案_引擎事实与三层分工_2026-10-10.md` 落成了 **E1/E2/E3 全部完成**

## 三、真机跑出来的两个坑（都成判据了）

① **`show ... :` 的冒号不是属性**。脚本里真有 `show ling heihei:` 跟一个 ATL 块
（`zoom 0.15` / `yoffset 200`），冒号是**块开始**。不剥掉就报出 `heihei:` 这种
不存在的属性名，还把同一属性拆成 `heihei` / `heihei:` 两条 ——
**真机汇总从 5 处虚报成 31 处**（`_show_item_attr` 修，两处共用）。
修完与 lint 报告对上了：

```
lan: sideeye、lose、blankface    ling: care    ye: uh      （共 5 处、3 个角色）
```

② **夹具的 `attributes` 形状是按 tag 分组的**（`{'lan': [{'group':…}]}`）。
我第一版写成平铺列表 → `attributes_of(facts,'lan')` 恒为空 → 判据以
"两边都是空集 → 相等"的**假象**通过。现在有一条**夹具自检**
（`test_the_fixture_really_carries_facts`）专门钉这件事 ——
"判据自己错了"在本仓已经是第 N 次，值得一个固定手法。

③ 层归属上也纠了一次：我起初把汇总写进 `session_assets`（会想 import beat 语义），
**那是 app 层的活**。按本仓分工改成"会话出数据、app 层出文案"。
