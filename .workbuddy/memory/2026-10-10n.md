## 二、⭐⭐ 地狱测试四个新发现（都有实测）

| 洞 | 证据 | 危害 |
|---|---|---|
| **1 扫描盲区** | **C4**：CDS 名拼出来（`"wea"+"ther3"`）→ 引擎**接受** `weather3`，扫描器（只认字面量）**看不见** | 工具会**静默认为"项目里没有这个写法"** → 措辞必须改成"**我认出了 N 个**" |
| **2 覆盖内置语句可行且无信号** | **C16**：`register_statement("pause", parse=必报错)` → lint 报 `SG-OVERRIDE` ⇒ **覆盖真的生效**；**C7**：parse 不报错时 → **exit 0 毫无信号** | 用户假设的"改已有语句的解析规则"**用 CDS 就能做到**，今天工具链完全无察觉。**必须静态扫 `register_statement(<内置名>)` 并报警** |
| **3 同组属性冲突 lint 不查** | **C10**：`show lan happy sad`（同组）→ **exit 0，静默** | 编剧填了互斥属性，一路放行到运行期。**工具必须用枚举的 group 自查** |
| **4 parse error 连探针一起杀死** | **C13/C16/C17** 三个用例 `facts.json` **全部不产出**；C13 还证明非法属性被吞 | **"没采到"绝不能被当成"没有漂移"** → `probe_complete=false` 是**硬失败** |
