### 为什么必须上真引擎

`ui_qt.stage_preview`（🎬 演出预览）是 Pillow 按卡片重画的近似帧：改一句
看一眼够快，但 **transitions / ATL / screen 特效 / 项目自定义 UI / 小游戏 /
菜单交互** 全都不真。文案和策划手上没有 VSCode / Ren'Py / Python，所以只能
"工具 + 完整项目"两份东西里把引擎自带进去。

### 实现（`storygraph/app/engine_preview.py`）

1. **镜像**：在 `%LOCALAPPDATA%\StoryGraph\engine_preview\<项目>-<hash>\project\`
   里搭副本 —— `.rpy` / `.rpyc` 逐字节复制（保留 mtime → 引擎不重编译），
   图片 / 音乐 / 字体这种大目录用 **junction**（不复制、不占空间）。
   原项目**一个字节都不写**（判据：文件 hash + mtime 前后比对）。
2. **注入入口**：镜像 `game/` 里多一个 `zzz_storygraph_engine_preview.rpy`：
   `config.label_overrides["start"]` 指到注入 label，再 `jump <目标>`。
   配合引擎自己的环境变量 `RENPY_SKIP_SPLASHSCREEN` / `RENPY_SKIP_MAIN_MENU`
   —— 不用改项目的 `screens.rpy`，也不会和项目的魔改打架。
3. **隔离用户目录**：`--savedir` 指到镜像；`APPDATA` / `HOME` 也重定向进镜像；
   `RENPY_DISABLE_BACKUPS` 关掉"备份脚本到用户真实 %APPDATA%"（这个坑一开
   就发现 `%APPDATA%\RenPy\backups` 已堆了几百个目录）。
4. **两种入口**：章首跳 `<label>_control`（工具生成的编排层，进章 + 后续菜单
   都串起来）；「从这一拍」用 `--warp game/file.rpy:行号`（近似，前情变量缺，
   UI 先问"要章首还是近似"）。
5. **真机验证截图**：不能用 `PIL.ImageGrab` 截窗口 —— 游戏窗口被别的窗口
   挡住时，截到的是挡在前面的 DSH 侧栏，上次因此把"跑得好好的引擎"误判成
   "黑屏卡住"。改成在镜像里注入 `config.periodic_callbacks` + `renpy.screenshot`，
   由引擎自己出图，窗口被遮住也不影响。

### 两个差点毁项目的坑（都已修 + 判据）

1. **目录从"资源"变成"脚本目录"时，必须先摘 junction 再复制**：某个资源
   目录上次没有 `.rpy`、整棵 junction 到项目里；这次加了 `.rpy` 要逐层复制。
   如果先复制，`dst` 落在 junction 里，`shutil.copy2` 会**写进用户真实目录**
   —— 工具"复制一个文件"，用户的源文件就被改了。
2. **Windows 不区分大小写**：`(root/'game').is_dir()` 会把项目旁边的
   `Game/` 也认成项目，于是"选错一层目录"被当成合法项目（`find_received_project`
   实测踩到：`pkg/项目/Game/game` 被识别成 `pkg/项目`）。所有判断改成
   `os.scandir` + 名字精确等于 `game`。

### 自动打开 / 自动补预设（`storygraph/app/stage_edition.py`）

- `find_received_project()`：`项目/` → `project/` → 包目录自己 → 上一级 →
  （打包版）唯一带 game/ 的子目录；**有歧义返回 None**（不猜）。
- `apply_presets()`：只补缺 —— 项目里有 `storygraph.rules.json`（根或 `game/`）
  或布局（`.storygraph/layout.json` 或旧 `storygraph_layout.json`）就一个字节
  不动；写的时候临时文件 + `os.replace`，不会留半份 JSON。
- 只在 `stage_edition()`（exe 旁边有 `演出专用版.txt` 或设了环境变量）生效，
  标准版行为完全不变（不写项目、不自动换项目）。
- `open_project_path` 是唯一入口：手动打开 / 自动打开 / 记忆恢复都过它。

### 一句教训

### 踩坑补记（收尾阶段，都是全量测试抓出来的）

- `tests/test_no_undefined_names.py` 用 symtable 扫**函数级**的全局名：
  函数里读 `__file__` 会被判成"看不见的全局名"。→ 仓库根改成**模块级**常量
  `_SOURCE_ROOT = Path(__file__).resolve().parents[2]`。
- `tests/test_code_health.py` 会把**任何只有 `pass` 的 except 体**都报成静默
  吞异常（不分异常类型）。→ 镜像清理/删临时文件那些 `except OSError: pass`
  全部改成 `except OSError as e: swallow(...)`。
- 跑全量时若同时开 PyInstaller，6 个 xdist worker 会 `0x8007000e`（内存不够
  import PySide6）；**构建与全量别并行**，worker 用 4。
