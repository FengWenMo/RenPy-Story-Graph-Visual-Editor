### 三、深挖设计结构（本次核心产出）

派 4 路并行探索（身份指纹 / 门禁守卫 / 引擎三态 / UI应用层），再用**独立脚本复验**所有指控。

**四条设计主线**：

1. **身份分层**——`line_id`(坐标) / `content_hash`(16hex, 语句) / `beat_fingerprint`(10hex, 拍)
   三者**刻意互不替代**，各有 note 写明理由（`beat_fields.py` 的 `FieldSpec.note` 强制豁免必须写理由，
   `test_beat_field_contract.py:131` 断言空 note 即红）。
   `Statement.__eq__` 排除 `source`（位置是坐标不是语义）；CST 用**动态属性**挂载而不进 dataclass
   字段——因为相等/哈希是全局契约。
   `content_hash` 16 位有完整生日碰撞论证（8 位=32bit，7.7 万条 65% 撞一次）；**10 位那个没有**。
2. **空缺三态**——`facts`(带 source) / `gaps`(带 reason) / `derived`(自己算)。`('probe',{})`=采到了但是空
   vs `('probe',None)`=没取到，**空 ≠ 缺失**贯穿四层未塌回布尔。
3. **写入门禁**——目标侧（`_looks_handwritten`/`merging_onto`）与产物侧（`generation_guard`）分开判；
   拦下时不写目标 + 另存 `.blocked.rpy` 到**引擎扫不到**的地方 + 主动发通知（否则界面显示"导出完成"）。
   预检与门禁**故意不共用结论**（预检不替门禁放行）。
4. **缓存粒度**——`scan_cache` 三层判据（文件 mtime_ns+size / 项目全表指纹 / 目录 mtime），**零 TTL**。
   最阴的一类 bug 被明确识别并挡住："缓存了却没有任何东西能让它失效"。

**贯穿纪律**："让失败可见"（缺 token 返洋红 `#FF00FF`、未知 key 必须报出来、通知不吞异常）。

**缺口①（P0，静默改身份）** `story/line_identity.py:89-98` `unique_ids()` 级联改号：
```
before: ['ch01.0001','ch01.0001','ch01.0002']
after : ['ch01.0001','ch01.0002','ch01.0003']   ← 第3行（从未重号）被改身份
```
原因：`allocate(seen, label)` 只用**已扫过**的 seen 算 max+1，给重号行发了属于第三行的号。
**直接违反同模块服务的契约 R6/R7**（"删一行其余不变""移一行不变"）。
可达路径真实：`excel_import.py:66 → assign_identity → unique_ids`。
现有测试 `test_line_identity_contract.py:311` 用 `['a.0001','a.0002','a.0001']`——**重复在最后恰好避开**，
顺序一换就崩。修法：分配时用**全批 ID 集合**算占用，或两轮（先给所有重号行发号再统一去重）。

**缺口②（P1）** `core/engine_facts.py` `validate_facts()` **完全不校验 `derived` 段**（facts 段逐条查
未知键/缺 source/缺 value，derived 一个字不查）；`DERIVED_KEYS` 声明了 `group_conflicts` 但
`engine_collect.py:616` **从来不写它**（只是同名函数在查询层）→ 同名不同层。
且 derived **没有 `derived_gaps`** 通道 → `_derived_overridden_builtins` 异常被 swallow 后 `return []`
与"项目确实没覆盖内置"**在文件里长得一模一样**。

**缺口③（P2，守卫漏一个写法）** `tests/test_single_write_entry.py` 的 `_is_write_call` 只读
`node.args[1:]`（位置参数），**不看 `node.keywords`**。实测：
`open(p,'w')`→True，`open(p,'wb')`→True，**`open(p, mode='w')`→False**，`open(p, mode='wb')`→False。
即**存在一条绕过"唯一写入口"架构底线的真实写路径**。当前 `storygraph/` 里无此写法（洞未被踩），
但守这条底线的守卫有洞。修法：`node.args[1:]` 加上 `node.keywords` 里 `arg=='mode'` 的值。

**附带（无功能后果）** `_FACTORY_FIELDS` 漏声明 3 个真实 payload 键：`say.tail` / `menu.extras` /
`return.value`（默认调用时 payload 里没这些键，**显式传参才出现**——所以 `test_kind_declaration_sync`
的 `_samples()` 用默认值调用工厂就永远测不到）。`validate_hash_contract()` 返回 []（只查一个方向）。
