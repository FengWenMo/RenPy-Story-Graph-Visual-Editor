## 第三轮：空引号专项（用户观察项，实测比"序号少 1"贵得多）

`_atoms` 里 `if text: out.append(...)` —— 引号内容为空时既不进词也不记毛病。

实测后果（`tools/probe_empty_quote.py`）：
1. **值前移 + 绿灯（P0）**：`show lan "" base_swimsuit happy` → ok=True，
   服装=base_swimsuit、表情=happy（人写的是 4 个位置、第 3 个是空）。
2. **报错指错格（P1）**：`show "" lan happy` → 报"第 3 格（服装）缺词"，
   实际缺的是第 2 格（角色）。
3. **读值侧同步前移**：`_claim('lan "" base_swimsuit happy')` → {0:lan,1:base_swimsuit,2:happy}。
4. **两侧词法不一致**：写回用 `positional_tokens`（**保留** `""`），切分用 `_atoms`（丢掉）
   → `set_slot_value` 把 `""` 留在行里，还把 happy 顶掉。
5. **词号偏移真凶不是空引号**：`show 小明泳装`（人按空格数 2 词）报"第 4 个词"/
   "共 3 个词" —— `_split_atom` 拆词后 token 序号冒充了人的词号，中文常态。

新增 `tests/test_cut_empty_quote.py`：**12 红 / 4 绿**（4 绿是引号护栏）。
方案（未落地，等用户批）：A 只报毛病 / B 占位+报毛病（推荐，需连带改 `slot_span` 的空值定位）/

## 第四轮：dead 的归属是代价选的，不是位置定的（用户观察项的第二层）

用户已实现 `EMPTY_TOKEN('\x00')` + `dead` + `broken`（两遍 `_spans`），三轮 53 条全绿。
用户观察：`show lan "" base_swimsuit happy` 一格 multi 时两词都晾着。

实测（`tools/probe_dead_offlist.py`）分出两层：
1. **P0：dead 归属由代价决定**。只「服装」multi、表情必填时 `broken=[3]`（表情），
   服装=base_swimsuit → **值整体左移一格**。因为空引号对任何格免费、
   多值格还能不吃（也 0），DP 会把空引号推给下一格。
   → 修法 A：`solve` 里 `tokens[ti] == EMPTY_TOKEN` 且是取值格时，唯一分支=吃掉它（~6 行）。
2. **P1：dead 格候选词仍按 `COST_OFFLIST(5)` 计价**。multi 吃 5 vs 空着+晾 3 → 不接。
   → 修法 B：`_tok_cost` 对"只属于 dead 格"的词返回 `COST_UNKNOWN(2)`（~4 行）。
A+B 实测后三种 multi 组合都收敛到"服装=''、表情=base_swimsuit、happy 多余"，
与"都不 multi"的参照系一致；垃圾词/mypose/偷词/正常行无变化。
新增 `tests/test_cut_dead_positions.py`：**4 红 / 5 绿**。
边界：空引号在开头（`show "" lan base_swimsuit happy`）A+B 后是
角色=''、服装=lan、表情空、base_swimsuit+happy 晾着（活格服装的候选，表情不许抢）——
多写一个值的正当报错，不纳入断言。

### 结构上的两个决定（不是调数字糊过去的）

1. **删掉 `POLICIES` / `policy=` 参数**。两套策略 = 同一行两个格子值
   （试切 `服装=junk`、卡片 `服装=base_swimsuit`）。现在"跳过垃圾词去认自己的
   候选"进了代价表，`match_line` 与 `_claim` **逐字同源**。

   与 `docs/契约速查_storygraph.md` 同步改了。
2. **代价表按"这一格有没有候选"分档**（`_tok_cost`）：
   `COST_OWN 0` / `COST_UNKNOWN 2`（随便写的格子吃自由文本）/
   `COST_BORROW 8`（随便写的格子**借**别人写明的候选）/
   `COST_OFFLIST 5`（闭枚举吃候选外的词 = 值不在候选里）/
   `COST_STOLEN 20`（闭枚举**抢**别人写明的候选）/ `EMPTY_SLOT 7` /
   `SKIP_WORD 3` / `SKIP_JUNK 1` / `COST_EXTRA 2`。
   · 20 > 7+3 = 10 → **偷词永远不划算**（旧 8 < 10 → 偷永远赢，`show lan lan`
     会给出一条不存在的服装报绿灯）；
   · 8 被 7（不许拿别人的词顶必填格）与 9（`mypose happy sad at left` 要人物拿到
     `happy`）夹在中间，只剩 1 点余量 —— 改这三个数之前先看判据。
3. **跳过垃圾词现在要付 `SKIP_JUNK + SKIP_WORD`**（被跳过的词最后必然进
   `leftover`，只记 1 等于让跳过免费 —— 这正是 `clothes2 junk happy` 与
   `小明 龙袍 泳装` 结果飘的原因）。
4. **optional 段也会跳过垃圾词**：`show lan junk at left happy` 不再把 `junk`
   塞进表情、把 `at left` 整段丢掉。
