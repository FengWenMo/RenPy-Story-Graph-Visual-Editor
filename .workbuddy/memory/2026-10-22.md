## 控制流卡第三阶段：删边 / 重载删幽灵 / skipped / 退休手动同步

文档 `docs/控制流卡_第三阶段_2026-10-22.md`。

### 删边的安全线
`rebuild_source_edges(..., allow_remove=True)` 只删**带 `line_id` 的 `source`
边**（说明它确实由上一轮 `flow_edges` 派生过）。没有 `line_id` 的老边保留，
避免升级后第一次重载误删历史数据；`manual` 一条不动。

解析有错时：节点对账整步跳过，边派生 `allow_remove=False`。**半份 AST
不能当"源里删了"**，否则一个语法错误就能吃掉整章连线。

### 重载删幽灵（P2-1）
`_prune_missing_source_nodes`：`node.file_path` 属于这次重载的文件，且
`label` 不在 `parse_result.labels` → `remove_node`（连同入边 / 出边）。
返回 `removed_nodes`，状态栏与日志都报；整次导入仍可 Ctrl+Z。

### `line_id` 重排
插卡 / 删卡后 `EditorSession._renumber()` 会把后面的拍全换 ID。派生分两轮：
先按 `line_id` 精确配，再按 `(from,to,type)` 顺序认领并**改挂新 ID**；
只用一轮会匹配不上、重复画边。`identified` 也包含"换新 ID"的条数。

### 退休 `_sync_flow_edge`
保存 / 导航提交 / 插卡 / 删卡 / 恢复 / **撤销这一拍**，全部改走
`_refresh_flow_edges()`。无变化（`added/retargeted/removed` 全 0）不重建
画布。实测 `rebuild`：3k 拍 0.48ms、10k 2.23ms、20k 9.44ms；保存不拖。
图边**不再进图级撤销栈**（它是派生物）；撤销控制流改动用卡片页「↩ 撤销修改」，

### 复查结论：三项本身没 bug，但抓到一个"假撤销"
用真实路径跑了一遍：块首插入 → **原地补丁导出** → 重新解析（if / while /
顶层三种都对；`python:` 块 `code_blocks` 边界没挤乱）；关窗用 `QTimer` +

### 假撤销（本轮修的 bug）

整份 `beats` 深拷贝会换掉一批对象，引用全指旧拍）。
⚠ `Beat` 是 dataclass（`__eq__` 比字段）：找拍下标要用 `b is beat`，
`list.index()` 会把内容相同的两拍认成同一拍。撤销后 `refresh_edits_flag()`
重算 → "加了又撤"回到「✔ 已同步」。

嵌套 `if` 在拍模型里是合并条件（`if (a) and (b):`），块清单照实显示。

### 判据
12 条新增（块清单 / 下拉 / 不选也能插 / 块尾锚在循环体 / 老三项不变 /

2. 两个块文本可能完全相同 → 落地必须按顺序**配对**语句（`used_idx`），
